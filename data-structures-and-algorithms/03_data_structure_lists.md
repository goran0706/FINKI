## Еднострано поврзани листи (Singly Linked Lists — SLL)

### Дефиниција

Еднострано поврзана листа (Singly Linked List — SLL) е динамичка податочна структура составена од јазли кои се поврзани
преку покажувачи.

Секој јазол содржи две полиња:

- `DATA` (`data`) – ја содржи вредноста на јазолот.
- `LINK` (`link`) – содржи покажувач или референца кон следниот јазол во листата.

Класата `SLL` содржи покажувач `FIRST`, кој ја означува адресата на првиот јазол.

Пример:

```text
FIRST
  |
  v
[ant | link] → [bat | link] → [cat | NULL]
```

Последниот јазол има `LINK = NULL`, бидејќи нема следен јазол.

Празната листа не содржи ниту еден јазол, па затоа:

```text
FIRST = NULL
```

Должината на листата претставува број на јазли што ги содржи. Таа може динамички да се зголемува или намалува во
зависност од достапната меморија.

### Основни својства

- Јазлите се поврзани преку покажувачи или референци.
- Јазлите не мора да бидат сместени на последователни мемориски локации.
- Листата нема однапред определена максимална големина.
- Почетокот на листата се одредува преку покажувачот `FIRST`.
- Последниот јазол има `LINK = NULL`.
- Празната листа се означува со `FIRST = NULL`.
- Нема директен пристап до произволен јазол, како кај низите.
- За пристап до определен јазол потребно е изминување од почетокот на листата.
- Секој јазол, освен првиот, има претходник.
- Секој јазол, освен последниот, има следбеник.
- Не постои директна врска од еден јазол до неговиот претходник.
- При вметнување и бришење се менуваат врските меѓу јазлите, без поместување на останатите јазли.
- Вметнувањето на почетокот и бришењето на првиот јазол имаат временска сложеност `O(1)`.
- Вметнувањето на крајот и бришењето на последниот јазол бараат изминување на листата и имаат сложеност `O(n)`.

### Основни операции

Над еднострано поврзаните листи може да се извршуваат следните операции:

1. Креирање празна листа.
2. Изминување на листата.
3. Пребарување елемент.
4. Вметнување елемент на почетокот.
5. Вметнување елемент на крајот.
6. Вметнување елемент по даден јазол.
7. Бришење на првиот јазол.
8. Бришење на последниот јазол.
9. Бришење јазол со определена вредност.
10. Бришење јазол по даден претходник.
11. Бришење на целата листа.

#### Креирање празна листа

Цел: Иницијализација на празна еднострано поврзана листа.

| Карактеристика      | Опис         |
|---------------------|--------------|
| Предуслов           | Нема         |
| Резултат            | Празна листа |
| Временска сложеност | `O(1)`       |
| Просторна сложеност | `O(1)`       |

Алгоритам:

1. Започни.
2. Креирај нова празна листа.
3. Постави го покажувачот `FIRST` на `NULL`.
4. Заврши.

Пример:

```text
Пред:

Листата не постои.

По иницијализација:

FIRST = NULL
```

Java имплементација:

```java
public class SLL() {
    private final Node first;

    public SLL() {
        first = null;
    }
}
```

Објаснување: При креирање на празна листа, покажувачот `first` се поставува на `null`. Тоа означува дека листата не
содржи ниту еден јазол.

#### Изминување на листата

Цел: Да се посетат сите јазли на листата точно по еднаш, почнувајќи од првиот јазол.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Листата е иницијализирана |
| Резултат            | Сите јазли се посетени    |
| Временска сложеност | `O(n)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Постави го тековниот покажувач `CURR` на `FIRST`.
3. Додека `CURR != NULL`:
    - Прочитај ја вредноста `DATA(CURR)`.
    - Изврши ја потребната операција врз тековниот јазол.
    - Премини на следниот јазол преку `LINK(CURR)`.
4. Заврши кога `CURR` ќе стане `NULL`.
5. Заврши.

Пример:

```text
FIRST
  |
  v
[ant] → [bat] → [cat] → NULL

Редослед на посетување:

ant → bat → cat
```

Java имплементација:

```java
public void print() {
    Node curr = first;

    while (curr != null) {
        System.out.println(curr.data);
        curr = curr.link;
    }
}
```

Објаснување: Изминувањето започнува од `first`. Со секоја итерација, `curr` се поместува кон следниот јазол преку
`link`. Постапката завршува кога `curr` ќе стане `null`. Секој јазол се посетува точно еднаш, па временската сложеност е
`O(n)`.

#### Пребарување елемент

Цел: Да се пронајде јазол кој содржи определена вредност `x`.

| Карактеристика                        | Опис                                           |
|---------------------------------------|------------------------------------------------|
| Предуслов                             | Листата е иницијализирана                      |
| Резултат                              | Пронајден јазол или информација дека не постои |
| Временска сложеност – најдобар случај | `O(1)`                                         |
| Временска сложеност – просечен случај | `O(n)`                                         |
| Временска сложеност – најлош случај   | `O(n)`                                         |
| Просторна сложеност                   | `O(1)`                                         |

Алгоритам:

1. Започни.
2. Прими ја бараната вредност `x`.
3. Постави `CURR = FIRST`.
4. Додека `CURR != NULL`:
    - Провери дали `DATA(CURR) == x`.
    - Ако условот е исполнет, врати го пронајдениот јазол.
    - Во спротивно, премини на следниот јазол.
5. Ако се стигне до `NULL`, врати `NULL`.
6. Заврши.

Пример:

```text
FIRST → [ant] → [bat] → [cat] → NULL

Барана вредност: bat

Резултат:

ant → bat (пронајден)
```

Java имплементација:

```java
public Node search(String value) {
    Node curr = first;

    while (curr != null) {
        if (Objects.equals(curr.data, value)) {
            return curr;
        }

        curr = curr.link;
    }

    return null;
}
```

Објаснување: Бидејќи еднострано поврзаната листа нема директен пристап до произволен јазол, пребарувањето се врши
последователно. Во најдобар случај, бараната вредност се наоѓа во првиот јазол. Во најлош случај, се проверуваат сите
јазли или елементот воопшто не постои.

#### Вметнување елемент на почетокот

Цел: Додавање нов јазол пред моментално првиот јазол на листата.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Листата е иницијализирана |
| Резултат            | Новиот јазол станува прв  |
| Временска сложеност | `O(1)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Прими ја вредноста `Y` што треба да се вметне.
3. Креирај нов јазол `X`.
4. Запиши ја вредноста `Y` во `DATA(X)`.
5. Постави `LINK(X) = FIRST`.
6. Постави `FIRST = X`.
7. Заврши.

Пример:

```text
Пред:

FIRST → [bat] → [cat] → NULL

Вметни: ant

Потоа:

FIRST → [ant] → [bat] → [cat] → NULL
```

Java имплементација:

```java
public void insertFirst(String value) {
    Node x = new Node(value);

    x.link = first;
    first = x;
}
```

Објаснување: Новиот јазол прво се поврзува со досегашниот прв јазол преку `x.link = first`. Потоа `first` се ажурира да
покажува кон новиот јазол. Ако листата била празна, новиот јазол истовремено станува и прв и последен јазол. Операцијата
има временска сложеност `O(1)` бидејќи не е потребно изминување на листата.

#### Вметнување елемент на крајот

Цел: Додавање нов јазол по последниот јазол на листата.

| Карактеристика      | Опис                          |
|---------------------|-------------------------------|
| Предуслов           | Листата е иницијализирана     |
| Резултат            | Новиот јазол станува последен |
| Временска сложеност | `O(n)`                        |
| Просторна сложеност | `O(1)`                        |

Алгоритам:

1. Започни.
2. Прими ја вредноста `Y` што треба да се вметне.
3. Креирај нов јазол `X`.
4. Запиши ја вредноста `Y` во `DATA(X)`.
5. Постави `LINK(X) = NULL`.
6. Провери дали листата е празна:
    - Ако `FIRST = NULL`, постави `FIRST = X`.
    - Во спротивно:
        - Постави `CURR = FIRST`.
        - Додека `LINK(CURR) != NULL`, преминувај на следниот јазол.
        - Постави `LINK(CURR) = X`.
7. Заврши.

Пример:

```text
Пред:

FIRST → [ant] → [bat] → NULL

Вметни: cat

Потоа:

FIRST → [ant] → [bat] → [cat] → NULL
```

Java имплементација:

```java
public void insertLast(String value) {
    Node x = new Node(value);

    if (first == null) {
        first = x;
        return;
    }

    Node curr = first;

    while (curr.link != null) {
        curr = curr.link;
    }

    curr.link = x;
}
```

Објаснување: Ако листата е празна, новиот јазол станува прв. Во спротивно, со помош на `curr` се пронаоѓа последниот
јазол, односно јазолот чија врска `link` е `null`. Потоа неговата врска се менува да покажува кон новиот јазол. Бидејќи
е потребно изминување на листата, временската сложеност е `O(n)`.

#### Вметнување елемент по даден јазол

Цел: Вметнување нов јазол веднаш по определен постоен јазол `CURR`.

| Карактеристика      | Опис                              |
|---------------------|-----------------------------------|
| Предуслов           | `CURR` е валиден јазол во листата |
| Резултат            | Новиот јазол е вметнат по `CURR`  |
| Временска сложеност | `O(1)` ако `CURR` е познат        |
| Просторна сложеност | `O(1)`                            |

Алгоритам:

1. Започни.
2. Прими го јазолот `CURR` и вредноста `Y`.
3. Креирај нов јазол `X`.
4. Запиши ја вредноста `Y` во `DATA(X)`.
5. Постави `LINK(X) = LINK(CURR)`.
6. Постави `LINK(CURR) = X`.
7. Заврши.

Псевдокод:

```text
procedure INSERT_AFTER(CURR, Y)

    DATA(X) ← Y
    LINK(X) ← LINK(CURR)
    LINK(CURR) ← X

end INSERT_AFTER
```

Пример:

```text
Пред:

FIRST → [dog] → [fox] → NULL

Вметни eel по dog.

Потоа:

FIRST → [dog] → [eel] → [fox] → NULL
```

Java имплементација:

```java
public void insertAfter(Node curr, String value) {
    if (curr == null) {
        return;
    }

    Node x = new Node(value);

    x.link = curr.link;
    curr.link = x;
}
```

Објаснување: На новиот јазол прво му се доделува врската кон следниот јазол на `curr`. Потоа `curr` се поврзува со
новиот јазол. Редоследот е важен бидејќи во спротивно може да се изгуби врската со останатите јазли. Ако `curr` е
однапред познат, операцијата има временска сложеност `O(1)`. Ако треба прво да се пронајде, сложеноста е `O(n)`.

#### Бришење на првиот јазол

Цел: Отстранување на првиот јазол од листата.

| Карактеристика      | Опис                     |
|---------------------|--------------------------|
| Предуслов           | Листата не е празна      |
| Резултат            | Првиот јазол е отстранет |
| Временска сложеност | `O(1)`                   |
| Просторна сложеност | `O(1)`                   |

Алгоритам:

1. Започни.
2. Провери дали `FIRST = NULL`.
3. Ако листата е празна, заврши.
4. Во спротивно:
    - Зачувај го првиот јазол во `X`.
    - Постави `FIRST = LINK(X)`.
5. Заврши.

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat] → NULL

Избриши го првиот јазол.

Потоа:

FIRST → [bat] → [cat] → NULL
```

Java имплементација:

```java
public void deleteFirst() {
    if (first == null) {
        return;
    }

    first = first.link;
}
```

Објаснување: Покажувачот `first` се поместува да покажува кон вториот јазол. Претходниот прв јазол повеќе не е дел од
листата. Ако листата содржела само еден јазол, по бришењето `first` станува `null`. Операцијата има константна временска
сложеност.

#### Бришење на последниот јазол

Цел: Отстранување на последниот јазол од листата.

| Карактеристика      | Опис                         |
|---------------------|------------------------------|
| Предуслов           | Листата не е празна          |
| Резултат            | Последниот јазол е отстранет |
| Временска сложеност | `O(n)`                       |
| Просторна сложеност | `O(1)`                       |

Алгоритам:

1. Започни.
2. Провери дали `FIRST = NULL`.
3. Ако листата е празна, заврши.
4. Ако листата содржи само еден јазол:
    - Постави `FIRST = NULL`.
5. Во спротивно:
    - Постави `CURR = FIRST`.
    - Додека `LINK(LINK(CURR)) != NULL`, преминувај на следниот јазол.
    - Постави `LINK(CURR) = NULL`.
6. Заврши.

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat] → NULL

Избриши го последниот јазол.

Потоа:

FIRST → [ant] → [bat] → NULL
```

Java имплементација:

```java
public void deleteLast() {
    if (first == null) {
        return;
    }

    if (first.link == null) {
        first = null;
        return;
    }

    Node curr = first;

    while (curr.link.link != null) {
        curr = curr.link;
    }

    curr.link = null;
}
```

Објаснување: Ако листата има само еден јазол, неговото бришење ја прави листата празна. Во спротивно, се пронаоѓа
претпоследниот јазол, односно јазолот чиј следен јазол е последен. Неговата врска се поставува на `null`, со што
последниот јазол се исклучува од листата. Операцијата има временска сложеност `O(n)` бидејќи е потребно изминување на
листата.

#### Бришење јазол со определена вредност

Цел: Пронаоѓање и отстранување на првиот јазол што содржи определена вредност `x`.

| Карактеристика      | Опис                                     |
|---------------------|------------------------------------------|
| Предуслов           | Листата е иницијализирана                |
| Резултат            | Јазолот со бараната вредност е отстранет |
| Временска сложеност | `O(n)`                                   |
| Просторна сложеност | `O(1)`                                   |

Алгоритам:

1. Започни.
2. Провери дали `FIRST = NULL`.
3. Ако листата е празна, заврши.
4. Провери дали `DATA(FIRST) = x`:
    - Ако е точно, постави `FIRST = LINK(FIRST)`.
    - Заврши.
5. Постави `CURR = FIRST`.
6. Додека `LINK(CURR) != NULL`:
    - Провери дали `DATA(LINK(CURR)) = x`.
    - Ако е точно, постави `LINK(CURR) = LINK(LINK(CURR))`.
    - Заврши.
    - Во спротивно, премини на следниот јазол.
7. Заврши ако вредноста не е пронајдена.

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat] → [dog] → NULL

Избриши: cat

Потоа:

FIRST → [ant] → [bat] → [dog] → NULL
```

Java имплементација:

```java
public void delete(String value) {
    if (first == null) {
        return;
    }

    if (Objects.equals(first.data, value)) {
        first = first.link;
        return;
    }

    Node curr = first;

    while (curr.link != null) {
        if (Objects.equals(curr.link.data, value)) {
            curr.link = curr.link.link;
            return;
        }

        curr = curr.link;
    }
}
```

Објаснување: Прво се проверува дали бараната вредност се наоѓа во првиот јазол. Ако не е, се пребарува листата преку
`curr`. Кога ќе се пронајде јазолот што треба да се избрише, врската на неговиот претходник се менува да покажува кон
следниот јазол. Така, избришаниот јазол се исклучува од листата без поместување на останатите јазли.

#### Бришење средишен јазол

Цел: Отстранување на јазол кој се наоѓа меѓу два други јазли.

| Карактеристика      | Опис                                          |
|---------------------|-----------------------------------------------|
| Предуслов           | Познат е претходникот на јазолот што се брише |
| Резултат            | Средишниот јазол е отстранет                  |
| Временска сложеност | `O(1)` ако претходникот е познат              |
| Просторна сложеност | `O(1)`                                        |

Алгоритам:

1. Започни.
2. Прими го претходниот јазол `PREV`.
3. Провери дали `PREV != NULL` и `LINK(PREV) != NULL`.
4. Постави `X = LINK(PREV)`.
5. Постави `LINK(PREV) = LINK(X)`.
6. Заврши.

Псевдокод:

```text
X ← LINK(PREV)
LINK(PREV) ← LINK(X)
```

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat] → [dog] → NULL
                PREV     X

Избриши го bat.

Потоа:

FIRST → [ant] → [cat] → [dog] → NULL
```

Java имплементација:

```java
public void deleteAfter(Node prev) {
    if (prev == null || prev.link == null) {
        return;
    }

    Node x = prev.link;

    prev.link = x.link;
}
```

Објаснување: Претходниот јазол се поврзува директно со јазолот што следува по оној што се брише. На тој начин средишниот
јазол се исклучува од листата. Ако претходникот не е познат, потребно е негово пронаоѓање со изминување, па временската
сложеност станува `O(n)`.

#### Бришење на целата листа

Цел: Отстранување на сите јазли од листата и нејзино поставување во празна состојба.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Листата е иницијализирана |
| Резултат            | Празна листа              |
| Временска сложеност | `O(n)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Постави `CURR = FIRST`.
3. Додека `CURR != NULL`:
    - Зачувај ја врската кон следниот јазол во `NEXT`.
    - Отстрани го тековниот јазол.
    - Постави `CURR = NEXT`.
4. Постави `FIRST = NULL`.
5. Заврши.

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat] → NULL

По бришењето:

FIRST = NULL
```

Java имплементација:

```java
public void clear() {
    first = null;
}
```

Објаснување: Во Java, поставувањето на `first` на `null` ја отстранува единствената почетна референца кон листата.
Јазлите кои повеќе не се достапни од активни референци стануваат подобни за автоматско ослободување преку Garbage
Collector. Затоа не е потребно рачно ослободување на секој јазол.

### Временска сложеност на операциите

Нека `n` го означува бројот на јазли во листата.

| Операција                   | Временска сложеност |
|-----------------------------|---------------------|
| Креирање празна листа       | `O(1)`              |
| Изминување                  | `O(n)`              |
| Пребарување                 | `O(n)`              |
| Вметнување на почеток       | `O(1)`              |
| Вметнување на крај          | `O(n)`              |
| Вметнување по познат јазол  | `O(1)`              |
| Бришење на првиот јазол     | `O(1)`              |
| Бришење по вредност         | `O(n)`              |
| Бришење на последниот јазол | `O(n)`              |
| Бришење средишен јазол      | `O(1)`              |
| Бришење на целата листа     | `O(1)` во Java      |

Забелешка: `clear()` во прикажаната Java имплементација има `O(1)` сложеност бидејќи само ја менува почетната референца.
Ако се анализира експлицитно отстранување на секој јазол, временската сложеност е `O(n)`.

### Просторна сложеност

Ако листата содржи `n` јазли, вкупната просторна сложеност е:

$$
S (n) = \Theta (n)
$$

Секој јазол содржи:

- Едно информациско поле `DATA`.
- Едно покажувачко поле `LINK`.

Дополнително, класата `SLL` содржи еден покажувач `FIRST`, кој го означува почетокот на листата.

Помошните покажувачи што се користат при изминување, пребарување, вметнување и бришење заземаат константен дополнителен
простор, односно `O(1)`.

### Предности и недостатоци

Предности:

- Големината на листата може динамички да се менува.
- Не е потребно однапред дефинирање на максималниот број елементи.
- Не е потребно поместување на останатите јазли при вметнување и бришење.
- Вметнувањето на почетокот има сложеност `O(1)`.
- Бришењето на почетокот има сложеност `O(1)`.
- Вметнувањето по познат јазол има сложеност `O(1)`.
- Бришењето средишен јазол има сложеност `O(1)` ако е познат неговиот претходник.

Недостатоци:

- Нема директен пристап до произволен јазол.
- Пребарувањето бара последователно изминување на листата.
- Секој јазол зафаќа дополнителна меморија за `LINK`.
- Вметнувањето на крајот бара изминување ако не се одржува покажувач `TAIL`.
- Бришењето на последниот јазол бара пронаоѓање на претпоследниот јазол.
- Не постои директна врска до претходниот јазол.
- Бришењето на јазол според вредност бара претходно пронаоѓање на неговиот претходник.

Важна забелешка: Кај еднострано поврзаната листа последниот `LINK` е `NULL`. Кај кружната еднострано поврзана листа
последниот `LINK` повторно покажува кон првиот јазол. Кај двојно поврзаната листа секој јазол има две врски: `LLINK` и
`RLINK`. Овие структури имаат различна организација и различни алгоритми за работа.

## Кружно поврзани листи (Circular Linked Lists — CLL)

### Дефиниција

Кружно поврзана листа (Circular Linked List — CLL) е динамичка податочна структура составена од јазли кои се поврзани
преку покажувачи, при што последниот јазол повторно покажува кон првиот јазол.

Секој јазол содржи две полиња:

- `DATA` (`data`) – ја содржи вредноста на јазолот.
- `LINK` (`link`) – содржи покажувач кон следниот јазол во листата.

Класата `CLL` содржи покажувач `FIRST`, кој ја означува адресата на првиот јазол.

За разлика од еднострано поврзаната листа, кај кружната листа последниот јазол нема `LINK = NULL`, туку неговиот `LINK`
повторно покажува кон `FIRST`.

Пример:

```text
          FIRST
            |
            v
       [ant | link]
            |
            v
       [bat | link]
            |
            v
       [cat | link]
            |
            └──────────→ FIRST
```

Основни правила:

- Празната листа се означува со `FIRST = NULL`.
- Листата со еден јазол има врска што покажува кон самиот јазол.
- Последниот јазол секогаш покажува кон првиот јазол.
- Не постои завршен јазол чиј `LINK` е `NULL`.

Пример за празна листа:

text

```text
FIRST = NULL
```

Пример за листа со еден јазол:

text

```text
       FIRST
         |
         v
      [ant]
         |
         └────→ FIRST
```

Должината на листата претставува број на јазли што ги содржи. Таа може динамички да се зголемува или намалува во
зависност од достапната меморија.

### Основни својства

- Јазлите се поврзани преку покажувачи.
- Јазлите не мора да бидат сместени на последователни мемориски локации.
- Листата нема однапред определена максимална големина.
- Почетокот на листата се одредува преку покажувачот `FIRST`.
- Последниот јазол повторно покажува кон првиот јазол.
- Празната листа се означува со `FIRST = NULL`.
- Кај листа со еден јазол, неговиот `LINK` покажува кон самиот себе.
- Не постои директен пристап до произволен јазол, како кај низите.
- За пристап до определен јазол потребно е изминување од почетокот на листата.
- Не постои природен крај на листата, бидејќи последниот јазол е поврзан со првиот.
- Изминувањето мора да заврши кога покажувачот повторно ќе стигне до `FIRST`.
- При вметнување и бришење се менуваат врските меѓу јазлите, без поместување на останатите елементи.

### Основни операции

Над кружно поврзаните листи може да се извршуваат следните операции:

1. Изминување на листата.
2. Пребарување елемент.
3. Вметнување елемент на почетокот.
4. Вметнување елемент на крајот.
5. Вметнување елемент по даден јазол.
6. Бришење на првиот јазол.
7. Бришење на последниот јазол.
8. Бришење јазол по даден претходник.
9. Бришење на целата листа.

#### Изминување на листата

Цел: Последователно посетување на сите јазли, почнувајќи од првиот јазол и завршувајќи кога повторно ќе се стигне до
него.

| Карактеристика       | Опис                      |
|----------------------|---------------------------|
| Предуслов            | Листата е иницијализирана |
| Резултат             | Сите јазли се посетени    |
| Временска сложеност  | `O(n)`                    |
| Дополнителен простор | `O(1)`                    |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Постави `CURR = FIRST`.
4. Посети го тековниот јазол.
5. Премини на следниот јазол преку `LINK(CURR)`.
6. Повторувај додека `CURR != FIRST`.
7. Заврши.

Псевдокод:

```text
if FIRST = NULL then
    return
end if

CURR ← FIRST

do
    print(DATA(CURR))
    CURR ← LINK(CURR)
while CURR != FIRST
```

Пример:

```text
          FIRST
            |
            v
          [ant] → [bat]
            ^         |
            |         v
          [cat] ←─────┘

Редослед на посетување:

ant → bat → cat
```

Java имплементација:

```java
void print() {
    if (FIRST == null) {
        return;
    }

    Node CURR = FIRST;

    do {
        System.out.println(CURR.data);
        CURR = CURR.link;
    } while (CURR != FIRST);
}
```

Објаснување: Изминувањето започнува од `FIRST`. За разлика од еднострано поврзаната листа, тука не се проверува дали
`CURR != null`, бидејќи последниот јазол не покажува кон `null`. Наместо тоа, постапката завршува кога покажувачот
повторно ќе стигне до првиот јазол.

#### Пребарување елемент

Цел: Пронаоѓање на јазол кој содржи определена вредност `x`.

| Карактеристика       | Опис                                           |
|----------------------|------------------------------------------------|
| Предуслов            | Листата е иницијализирана                      |
| Резултат             | Пронајден јазол или информација дека не постои |
| Најдобар случај      | `O(1)`                                         |
| Просечен случај      | `O(n)`                                         |
| Најлош случај        | `O(n)`                                         |
| Дополнителен простор | `O(1)`                                         |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, елементот не постои.
3. Постави `CURR = FIRST`.
4. Провери дали `DATA(CURR) == x`.
5. Ако е точно, врати го пронајдениот јазол.
6. Во спротивно, премини на следниот јазол.
7. Повторувај додека `CURR != FIRST`.
8. Ако се стигне повторно до `FIRST`, елементот не постои.

Псевдокод:

```text
if FIRST = NULL then
    return NULL
end if

CURR ← FIRST

do
    if DATA(CURR) = x then
        return CURR
    end if

    CURR ← LINK(CURR)
while CURR != FIRST

return NULL
```

Пример:

```text
FIRST → [ant] → [bat] → [cat]
          ↑                |
          └────────────────┘

Барана вредност: bat

Резултат:

ant → bat (пронајден)
```

Java имплементација:

```java
Node search(String value) {
    if (FIRST == null) {
        return null;
    }

    Node CURR = FIRST;

    do {
        if (Objects.equals(CURR.data, value)) {
            return CURR;
        }

        CURR = CURR.link;
    } while (CURR != FIRST);

    return null;
}
```

Објаснување: Пребарувањето се врши последователно, почнувајќи од `FIRST`. Бидејќи листата е кружна, не може да се
користи условот `CURR != null`. Потребно е да се провери дали покажувачот повторно се вратил на почетниот јазол. Во
најдобар случај елементот е првиот јазол, а во најлош случај е последниот или воопшто не постои.

#### Вметнување елемент во листата

Вметнувањето елемент во кружно поврзана листа се изведува со создавање нов јазол и соодветно менување на врските
(`LINK`) меѓу јазлите.

При секое вметнување мора да се зачува кружната поврзаност, односно последниот јазол повторно да покажува кон `FIRST`.

#### Вметнување на почетокот на листата

Цел: Додавање нов јазол пред моментално првиот јазол.

| Карактеристика       | Опис                      |
|----------------------|---------------------------|
| Предуслов            | Листата е иницијализирана |
| Резултат             | Новиот јазол станува прв  |
| Временска сложеност  | `O(n)`                    |
| Дополнителен простор | `O(1)`                    |

Алгоритам:

1. Креирај нов јазол `X`.
2. Запиши ја вредноста `Y` во `DATA(X)`.
3. Провери дали листата е празна:
    - Ако `FIRST = NULL`:
        - Постави `FIRST = X`.
        - Постави `LINK(X) = X`.
    - Во спротивно:
        - Постави `CURR = FIRST`.
        - Додека `LINK(CURR) != FIRST`, преминувај на следниот јазол.
        - Постави `LINK(X) = FIRST`.
        - Постави `LINK(CURR) = X`.
        - Постави `FIRST = X`.
4. Заврши.

Псевдокод:

```text
procedure INSERT_FIRST(Y)

    create X
    DATA(X) ← Y

    if FIRST = NULL then
        FIRST ← X
        LINK(X) ← X
    else
        CURR ← FIRST

        while LINK(CURR) != FIRST do
            CURR ← LINK(CURR)
        end while

        LINK(X) ← FIRST
        LINK(CURR) ← X
        FIRST ← X
    end if

end INSERT_FIRST
```

Пример:

```text
Пред:

FIRST → [bat] → [cat]
          ↑       |
          └───────┘

Вметни: ant

Потоа:

FIRST → [ant] → [bat] → [cat]
          ↑                |
          └────────────────┘
```

Java имплементација:

```java
void insertFirst(String value) {
    Node X = new Node(value);

    if (FIRST == null) {
        FIRST = X;
        X.link = X;
        return;
    }

    Node CURR = FIRST;

    while (CURR.link != FIRST) {
        CURR = CURR.link;
    }

    X.link = FIRST;
    CURR.link = X;
    FIRST = X;
}
```

Објаснување: Ако листата е празна, новиот јазол станува единствен јазол и неговата врска покажува кон самиот себе. Ако
листата веќе содржи јазли, прво се пронаоѓа последниот јазол. Новиот јазол се поврзува со стариот прв јазол, последниот
јазол се поврзува со новиот, а `FIRST` се ажурира. Бидејќи се бара пронаоѓање на последниот јазол, сложеноста е `O(n)`.

#### Вметнување на крајот на листата

Цел: Додавање нов јазол по последниот јазол на листата.

| Карактеристика       | Опис                          |
|----------------------|-------------------------------|
| Предуслов            | Листата е иницијализирана     |
| Резултат             | Новиот јазол станува последен |
| Временска сложеност  | `O(n)`                        |
| Дополнителен простор | `O(1)`                        |

Алгоритам:

1. Креирај нов јазол `X`.
2. Запиши ја вредноста `Y` во `DATA(X)`.
3. Провери дали листата е празна:
    - Ако `FIRST = NULL`:
        - Постави `FIRST = X`.
        - Постави `LINK(X) = X`.
    - Во спротивно:
        - Постави `CURR = FIRST`.
        - Додека `LINK(CURR) != FIRST`, преминувај на следниот јазол.
        - Постави `LINK(CURR) = X`.
        - Постави `LINK(X) = FIRST`.
4. Заврши.

Псевдокод:

```text
procedure INSERT_LAST(Y)

    create X
    DATA(X) ← Y

    if FIRST = NULL then
        FIRST ← X
        LINK(X) ← X
    else
        CURR ← FIRST

        while LINK(CURR) != FIRST do
            CURR ← LINK(CURR)
        end while

        LINK(CURR) ← X
        LINK(X) ← FIRST
    end if

end INSERT_LAST
```

Пример:

```text
Пред:

FIRST → [ant] → [bat]
          ↑       |
          └───────┘

Вметни: cat

Потоа:

FIRST → [ant] → [bat] → [cat]
          ↑                |
          └────────────────┘
```

Java имплементација:

```java
void insertLast(String value) {
    Node X = new Node(value);

    if (FIRST == null) {
        FIRST = X;
        X.link = X;
        return;
    }

    Node CURR = FIRST;

    while (CURR.link != FIRST) {
        CURR = CURR.link;
    }

    CURR.link = X;

```

Објаснување: За да се вметне нов јазол на крајот, најпрво се пронаоѓа последниот јазол, односно оној чиј `LINK` покажува
кон `FIRST`. Потоа неговата врска се менува да покажува кон новиот јазол, а новиот јазол се поврзува со првиот. На овој
начин се зачувува кружната поврзаност.

#### Вметнување меѓу два јазли

Цел: Вметнување нов јазол веднаш по определен постоен јазол.

| Карактеристика       | Опис                                |
|----------------------|-------------------------------------|
| Предуслов            | Познат е јазолот по кој се вметнува |
| Резултат             | Новиот јазол е вметнат по него      |
| Временска сложеност  | `O(1)` ако јазолот е познат         |
| Дополнителен простор | `O(1)`                              |

Алгоритам:

Да претпоставиме дека сакаме да вметнеме нов јазол `X` по јазолот `CURR`.

1. Креирај нов јазол `X`.
2. Запиши ја вредноста `Y` во `DATA(X)`.
3. Постави `LINK(X) = LINK(CURR)`.
4. Постави `LINK(CURR) = X`.
5. Заврши.

Псевдокод:

```text
procedure INSERT_AFTER(CURR, Y)

    create X
    DATA(X) ← Y

    LINK(X) ← LINK(CURR)
    LINK(CURR) ← X

end INSERT_AFTER
```

Пример:

```text
Пред:

FIRST → [dog] → [fox]
          ↑       |
          └───────┘

Вметни eel по dog.

Потоа:

FIRST → [dog] → [eel] → [fox]
          ↑                |
          └────────────────┘
```

Java имплементација:

```java
void insertAfter(String existingValue, String value) {
    Node CURR = search(existingValue);

    if (CURR == null) {
        return;
    }

    Node X = new Node(value);

    X.link = CURR.link;
    CURR.link = X;
}
```

Објаснување: На новиот јазол прво му се доделува врската кон следниот јазол на `CURR`. Потоа `CURR` се поврзува со
новиот јазол. Ако `CURR` е последниот јазол, новиот јазол автоматски станува последен и неговата врска повторно покажува
кон `FIRST`.

Ако јазолот по кој треба да се вметне не е однапред познат, потребно е прво да се пронајде со пребарување, па вкупната
сложеност е `O(n)`.

#### Бришење елемент од листата

Бришењето елемент од кружно поврзана листа се изведува со промена на врските меѓу јазлите, така што јазолот што се брише
ќе биде исклучен од кружната структура.

При бришењето мора да се земат предвид три случаи:

- Листата е празна.
- Листата содржи само еден јазол.
- Листата содржи повеќе јазли.

#### Бришење на првиот јазол

Цел: Отстранување на првиот јазол од листата.

| Карактеристика       | Опис                     |
|----------------------|--------------------------|
| Предуслов            | Листата не е празна      |
| Резултат             | Првиот јазол е отстранет |
| Временска сложеност  | `O(n)`                   |
| Дополнителен простор | `O(1)`                   |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Провери дали листата содржи само еден јазол:
    - Ако `LINK(FIRST) = FIRST`, постави `FIRST = NULL`.
4. Во спротивно:
    - Постави `CURR = FIRST`.
    - Додека `LINK(CURR) != FIRST`, преминувај на следниот јазол.
    - Постави `FIRST = LINK(FIRST)`.
    - Постави `LINK(CURR) = FIRST`.
5. Заврши.

Псевдокод:

```text
procedure DELETE_FIRST

    if FIRST = NULL then
        return
    end if

    if LINK(FIRST) = FIRST then
        FIRST ← NULL
    else
        CURR ← FIRST

        while LINK(CURR) != FIRST do
            CURR ← LINK(CURR)
        end while

        FIRST ← LINK(FIRST)
        LINK(CURR) ← FIRST
    end if

end DELETE_FIRST
```

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat]
          ↑                |
          └────────────────┘

Избриши го првиот јазол.

Потоа:

FIRST → [bat] → [cat]
          ↑       |
          └───────┘
```

Java имплементација:

```java
void deleteFirst() {
    if (FIRST == null) {
        return;
    }

    if (FIRST.link == FIRST) {
        FIRST = null;
        return;
    }

    Node CURR = FIRST;

    while (CURR.link != FIRST) {
        CURR = CURR.link;
    }

    FIRST = FIRST.link;
    CURR.link = FIRST;
}
```

Објаснување: Ако листата содржи само еден јазол, неговото бришење ја прави листата празна. Ако содржи повеќе јазли, прво
се пронаоѓа последниот јазол. Потоа `FIRST` се поместува на вториот јазол, а последниот јазол се поврзува со новиот
`FIRST`. Така се зачувува кружната поврзаност.

#### Бришење на последниот јазол

Цел: Отстранување на последниот јазол од листата.

| Карактеристика       | Опис                         |
|----------------------|------------------------------|
| Предуслов            | Листата не е празна          |
| Резултат             | Последниот јазол е отстранет |
| Временска сложеност  | `O(n)`                       |
| Дополнителен простор | `O(1)`                       |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Ако листата содржи само еден јазол:
    - Постави `FIRST = NULL`.
4. Во спротивно:
    - Постави `CURR = FIRST`.
    - Додека `LINK(LINK(CURR)) != FIRST`, преминувај на следниот јазол.
    - Постави `LINK(CURR) = FIRST`.
5. Заврши.

Псевдокод:

```text
procedure DELETE_LAST

    if FIRST = NULL then
        return
    end if

    if LINK(FIRST) = FIRST then
        FIRST ← NULL
    else
        CURR ← FIRST

        while LINK(LINK(CURR)) != FIRST do
            CURR ← LINK(CURR)
        end while

        LINK(CURR) ← FIRST
    end if

end DELETE_LAST
```

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat]
          ↑                |
          └────────────────┘

Избриши го последниот јазол.

Потоа:

FIRST → [ant] → [bat]
          ↑       |
          └───────┘
```

Java имплементација:

```java
void deleteLast() {
    if (FIRST == null) {
        return;
    }

    if (FIRST.link == FIRST) {
        FIRST = null;
        return;
    }

    Node CURR = FIRST;

    while (CURR.link.link != FIRST) {
        CURR = CURR.link;
    }

    CURR.link = FIRST;
}
```

Објаснување: За да се избрише последниот јазол, мора да се пронајде претпоследниот јазол. Неговата врска се поставува да
покажува кон `FIRST`, со што последниот јазол се исклучува од листата. Иако листата е кружна, не постои директна врска
до претходниот јазол, па затоа е потребно изминување.

#### Бришење средишен јазол

Цел: Отстранување на јазол кој се наоѓа меѓу два други јазли.

| Карактеристика       | Опис                                          |
|----------------------|-----------------------------------------------|
| Предуслов            | Познат е претходникот на јазолот што се брише |
| Резултат             | Јазолот е отстранет                           |
| Временска сложеност  | `O(1)` ако претходникот е познат              |
| Дополнителен простор | `O(1)`                                        |

Алгоритам:

Да претпоставиме дека треба да се избрише јазолот `X`, а неговиот претходник е `PREV`.

1. Провери дали `PREV` и `X` се валидни јазли.
2. Постави `LINK(PREV) = LINK(X)`.
3. Ако `X = FIRST`, ажурирај го `FIRST` на следниот јазол.
4. Заврши.

Псевдокод:

```text
LINK(PREV) ← LINK(X)
```

Пример:

```text
Пред:

FIRST → [ant] → [bat] → [cat] → [dog]
          ↑                         |
          └─────────────────────────┘

PREV = ant
X = bat

Избриши го bat.

Потоа:

FIRST → [ant] → [cat] → [dog]
          ↑                |
          └────────────────┘
```

Java имплементација:

```java
void deleteAfter(Node PREV) {
    if (PREV == null || FIRST == null) {
        return;
    }

    Node X = PREV.link;

    if (X == FIRST && X.link == FIRST) {
        FIRST = null;
        return;
    }

    PREV.link = X.link;

    if (X == FIRST) {
        FIRST = X.link;
    }
}
```

Објаснување: Претходниот јазол се поврзува директно со следниот јазол на оној што се брише. Така, избришаниот јазол се
исклучува од кружната листа без поместување на останатите јазли. Ако претходникот е познат, операцијата има константна
временска сложеност.

#### Бришење на целата листа

Цел: Отстранување на сите јазли од кружно поврзаната листа.

| Карактеристика       | Опис                      |
|----------------------|---------------------------|
| Предуслов            | Листата е иницијализирана |
| Резултат             | Празна листа              |
| Временска сложеност  | `O(n)`                    |
| Дополнителен простор | `O(1)`                    |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Постави `CURR = FIRST.link`.
4. Додека `CURR != FIRST`:
    - Зачувај го следниот јазол во `NEXT`.
    - Продолжи кон следниот јазол.
5. Постави `FIRST = NULL`.
6. Заврши.

Java имплементација:

```java
void clear() {
    if (FIRST == null) {
        return;
    }

    Node CURR = FIRST.link;

    while (CURR != FIRST) {
        Node NEXT = CURR.link;
        CURR = NEXT;
    }

    FIRST = null;
}
```

Објаснување: Во Java не е потребно рачно ослободување на меморијата за секој јазол. Кога `FIRST` ќе се постави на
`null`, а ниту еден друг дел од програмата не ги задржува референците кон јазлите, тие стануваат достапни за
отстранување од garbage collector. Временската сложеност е `O(n)` ако јазлите се обработуваат последователно.

### Временска сложеност на операциите

Нека `n` го означува бројот на јазли во листата.

| Операција                    | Временска сложеност |
|------------------------------|---------------------|
| Креирање празна листа        | `O(1)`              |
| Изминување                   | `O(n)`              |
| Пребарување                  | `O(n)`              |
| Вметнување на почеток        | `O(n)`              |
| Вметнување на крај           | `O(n)`              |
| Вметнување по познат јазол   | `O(1)`              |
| Бришење на првиот јазол      | `O(n)`              |
| Бришење на последниот јазол  | `O(n)`              |
| Бришење по познат претходник | `O(1)`              |
| Бришење на целата листа      | `O(n)`              |

Забелешка: Наведените сложености за вметнување и бришење на почетокот се однесуваат на имплементација која одржува само
`FIRST`. Ако се одржува и покажувач кон последниот јазол, овие операции можат да се изведат со `O(1)`.

### Просторна сложеност

Ако листата содржи `n` јазли, вкупната просторна сложеност е:

$$
S (n)=\Theta (n)
$$

Секој јазол содржи:

- Едно информациско поле `DATA`.
- Едно покажувачко поле `LINK`.

Дополнително, класата `CLL` содржи еден покажувач `FIRST`, кој го означува почетокот на листата.

Помошните покажувачи што се користат при изминување и манипулација со листата заземаат константен дополнителен простор
`O(1)`.

### Предности и недостатоци

Предности:

- Динамичка промена на големината на листата.
- Не е потребно однапред дефинирање на максималниот број елементи.
- Последниот јазол е поврзан со првиот, со што се овозможува кружно изминување.
- Може да се започне со изминување од кој било познат јазол.
- Погодна е за задачи што бараат повторливо циклично движење низ елементите.
- Не е потребно поместување на елементите при вметнување и бришење.
- Вметнувањето по познат јазол има сложеност `O(1)`.

Недостатоци:

- Нема директен пристап до произволен јазол.
- Пребарувањето бара последователно изминување.
- Секој јазол зафаќа дополнителна меморија за `LINK`.
- Вметнувањето на почетокот бара пронаоѓање на последниот јазол ако се одржува само `FIRST`.
- Вметнувањето на крајот бара изминување ако не се чува покажувач кон последниот јазол.
- Бришењето на последниот јазол бара пронаоѓање на претпоследниот јазол.
- Потребно е посебно внимание при проверка на условите за завршување на изминувањето.
- Неправилно поставување на врските може да предизвика бесконечно изминување или прекин на кружната поврзаност.

Важна забелешка: Кај кружно поврзаната листа последниот јазол секогаш покажува кон `FIRST`. Кај обичната еднострано
поврзана листа последниот јазол покажува кон `NULL`. Оваа разлика е особено важна при изминување, пребарување,
вметнување и бришење на јазли.

Забелешка за Java имплементациите: Примерите претпоставуваат дека постои класа `Node` со полиња `data` и `link`, како и
поле `FIRST` во класата на листата. За пребарувањето се користи `Objects.equals()`, па потребно е
`import java.util.Objects;`. Кодот претставува одделни методи, а не целосна Java класа.

## Двојно поврзани кружни листи (Circular Doubly Linked Lists — CDLL)

### Дефиниција

Двојно поврзана кружна листа (Circular Doubly Linked List — CDLL) е динамичка податочна структура составена од јазли кои
се поврзани во кружна структура преку две врски: една кон претходниот и една кон следниот јазол.

Секој јазол содржи три полиња:

- `DATA` (`data`) – ја содржи вредноста на јазолот.
- `LLINK` (`left`) – содржи покажувач или референца кон претходниот јазол.
- `RLINK` (`right`) – содржи покажувач или референца кон следниот јазол.

Класата `CDLL` содржи два покажувачи:

- `FIRST` (`first`) – ја означува адресата на првиот јазол.
- `LAST` (`last`) – ја означува адресата на последниот јазол.

За разлика од обичната двојно поврзана листа, кај двојно поврзаната кружна листа двата краја се поврзани:

- `RLINK` на последниот јазол покажува кон првиот јазол.
- `LLINK` на првиот јазол покажува кон последниот јазол.

На овој начин се формира кружна структура во која може да се движиме и во двете насоки.

Пример:

```text
                  FIRST
                    |
                    v
              [ant]
             /     \
            /       \
       [cat]         [bat]
            \       /
             \     /
              [dog]
                |
                v
               LAST
```

Кружните врски се:

```text
FIRST.LLINK = LAST
LAST.RLINK  = FIRST
```

Основни правила:

- Празната листа се означува со `FIRST = NULL` и `LAST = NULL`.
- Првиот јазол нема `LLINK = NULL`, туку неговиот `LLINK` покажува кон последниот јазол.
- Последниот јазол нема `RLINK = NULL`, туку неговиот `RLINK` покажува кон првиот јазол.
- Кај листа со еден јазол, и `LLINK` и `RLINK` покажуваат кон самиот јазол.
- Секој јазол има директна врска кон претходниот и следниот јазол.
- Изминувањето може да се врши во двете насоки.

Пример за празна листа:

```text
FIRST = NULL
LAST  = NULL
```

Пример за листа со еден јазол:

```text
          FIRST, LAST
               |
               v
             [ant]
             /   \
            ^     |
            |_____|
```

Кај единечен јазол:

```text
ant.LLINK = ant
ant.RLINK = ant
```

Должината на листата претставува број на јазли што ги содржи. Таа може динамички да се зголемува или намалува во
зависност од достапната меморија.

### Основни својства

- Јазлите се поврзани преку две врски: `LLINK` и `RLINK`.
- Јазлите не мора да бидат сместени на последователни мемориски локации.
- Листата нема однапред определена максимална големина.
- Почетокот на листата се одредува преку `FIRST`.
- Крајот на листата се одредува преку `LAST`.
- `FIRST.LLINK` секогаш покажува кон `LAST`.
- `LAST.RLINK` секогаш покажува кон `FIRST`.
- Кај листа со еден јазол, двете врски покажуваат кон самиот јазол.
- Нема директен пристап до произволен јазол, како кај низите.
- За пристап до определен јазол потребно е изминување на листата.
- Можно е изминување од почетокот кон крајот преку `RLINK`.
- Можно е изминување од крајот кон почетокот преку `LLINK`.
- Не постои природен крај на листата, бидејќи првиот и последниот јазол се меѓусебно поврзани.
- При вметнување и бришење се менуваат врските меѓу јазлите, без поместување на останатите јазли.
- Вметнувањето на почетокот и на крајот има временска сложеност `O(1)` кога се одржуваат `FIRST` и `LAST`.
- Бришењето на првиот и последниот јазол има временска сложеност `O(1)`.
- Вметнувањето и бришењето по познат јазол имаат временска сложеност `O(1)`.
- За разлика од еднострано поврзаните листи, не е потребно изминување за пронаоѓање на претходникот на познат јазол.

### Основни операции

Над двојно поврзаните кружни листи може да се извршуваат следните операции:

1. Изминување на листата нанапред.
2. Изминување на листата наназад.
3. Пребарување елемент.
4. Вметнување елемент на почетокот.
5. Вметнување елемент на крајот.
6. Вметнување елемент по даден јазол.
7. Вметнување елемент пред даден јазол.
8. Бришење на првиот јазол.
9. Бришење на последниот јазол.
10. Бришење познат јазол.
11. Бришење јазол со определена вредност.
12. Бришење на целата листа.

#### Изминување на листата нанапред

Цел: Последователно посетување на сите јазли, почнувајќи од првиот јазол и движејќи се кон последниот преку `RLINK`.

| Карактеристика       | Опис                      |
|----------------------|---------------------------|
| Предуслов            | Листата е иницијализирана |
| Резултат             | Сите јазли се посетени    |
| Временска сложеност  | `O(n)`                    |
| Дополнителен простор | `O(1)`                    |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Постави `CURR = FIRST`.
4. Посети го тековниот јазол.
5. Премини на следниот јазол преку `RLINK(CURR)`.
6. Повторувај додека `CURR != FIRST`.
7. Заврши.

Псевдокод:

```text
if FIRST = NULL then
    return
end if

CURR ← FIRST

do
    print(DATA(CURR))
    CURR ← RLINK(CURR)
while CURR != FIRST
```

Пример:

```text
FIRST
  |
  v
[ant] ⇄ [bat] ⇄ [cat]
  ^                 |
  |_________________|

Редослед на посетување:

ant → bat → cat
```

Java имплементација:

```java
public void printForward() {
    if (first == null) {
        return;
    }

    Node curr = first;

    do {
        System.out.println(curr.data);
        curr = curr.right;
    } while (curr != first);
}
```

Објаснување: Изминувањето започнува од `first`. Со секоја итерација, `curr` се поместува кон следниот јазол преку
`right`. Бидејќи листата е кружна, последниот јазол повторно покажува кон првиот. Изминувањето завршува кога `curr`
повторно ќе стане еднаков на `first`.

Секој јазол се посетува точно еднаш, па временската сложеност е `O(n)`.

#### Изминување на листата наназад

Цел: Последователно посетување на сите јазли, почнувајќи од последниот јазол и движејќи се кон првиот преку `LLINK`.

| Карактеристика       | Опис                                       |
|----------------------|--------------------------------------------|
| Предуслов            | Листата е иницијализирана                  |
| Резултат             | Сите јазли се посетени во обратен редослед |
| Временска сложеност  | `O(n)`                                     |
| Дополнителен простор | `O(1)`                                     |

Алгоритам:

1. Провери дали `LAST = NULL`.
2. Ако листата е празна, заврши.
3. Постави `CURR = LAST`.
4. Посети го тековниот јазол.
5. Премини на претходниот јазол преку `LLINK(CURR)`.
6. Повторувај додека `CURR != LAST`.
7. Заврши.

Псевдокод:

```text
if LAST = NULL then
    return
end if

CURR ← LAST

do
    print(DATA(CURR))
    CURR ← LLINK(CURR)
while CURR != LAST
```

Пример:

```text

  |
  v

                    v
```

Java имплементација:

```java
public void printBackward() {
    if (last == null) {
        return;
    }

    Node curr = last;

    do {
        System.out.println(curr.data);

```

Објаснување: Изминувањето започнува од `last`. Со секоја итерација, `curr` се поместува кон претходниот јазол преку
`left`. Бидејќи листата е кружна, првиот јазол повторно покажува кон последниот преку својата врска `left`. Изминувањето
завршува кога `curr` повторно ќе стане еднаков на `last`.

Предноста на двојно поврзаната кружна листа е тоа што не е потребно создавање дополнителна структура или превртување на
листата за да се добие обратен редослед на елементите.

#### Пребарување елемент

Цел: Пронаоѓање на јазол кој содржи определена вредност `x`.

| Карактеристика       | Опис                                           |
|----------------------|------------------------------------------------|
| Предуслов            | Листата е иницијализирана                      |
| Резултат             | Пронајден јазол или информација дека не постои |
| Најдобар случај      | `O(1)`                                         |
| Просечен случај      | `O(n)`                                         |
| Најлош случај        | `O(n)`                                         |
| Дополнителен простор | `O(1)`                                         |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, елементот не постои.
3. Постави `CURR = FIRST`.
4. Провери дали `DATA(CURR) = x`.
5. Ако е точно, врати го пронајдениот јазол.
6. Во спротивно, премини на следниот јазол преку `RLINK(CURR)`.
7. Повторувај додека `CURR != FIRST`.
8. Ако се стигне повторно до `FIRST`, елементот не постои.

Псевдокод:

```text
if FIRST = NULL then
    return NULL
end if

CURR ← FIRST

do
    if DATA(CURR) = x then
        return CURR
    end if

    CURR ← RLINK(CURR)
while CURR != FIRST

return NULL
```

Пример:

```text
FIRST → [ant] ⇄ [bat] ⇄ [cat]
          ^                 |
          |_________________|

Барана вредност: bat

Резултат:

ant → bat (пронајден)
```

Java имплементација:

```java
public Node search(String value) {
    if (first == null) {
        return null;
    }

    Node curr = first;

    do {
        if (Objects.equals(curr.data, value)) {
            return curr;
        }

        curr = curr.right;
    } while (curr != first);

    return null;
}
```

Објаснување: Пребарувањето започнува од `first` и се движи нанапред преку `right`. Бидејќи листата е кружна, не се
користи условот `curr != null`. Наместо тоа, се проверува дали покажувачот повторно се вратил на почетниот јазол.

Во најдобар случај, бараната вредност се наоѓа во првиот јазол. Во најлош случај, се проверуваат сите јазли или
елементот воопшто не постои.

#### Вметнување елемент во листата

Вметнувањето елемент во двојно поврзана кружна листа се изведува со создавање нов јазол и соодветно менување на двете
врски (`LLINK` и `RLINK`) на соседните јазли.

При секое вметнување мора да се зачува кружната поврзаност во двете насоки:

- `FIRST.LLINK = LAST`.
- `LAST.RLINK = FIRST`.

За разлика од еднострано поврзаната листа, кај двојно поврзаната листа при вметнување мора да се ажурираат и врската кон
претходниот и врската кон следниот јазол.

#### Вметнување на почетокот на листата

Цел: Додавање нов јазол пред моментално првиот јазол.

| Карактеристика       | Опис                      |
|----------------------|---------------------------|
| Предуслов            | Листата е иницијализирана |
| Резултат             | Новиот јазол станува прв  |
| Временска сложеност  | `O(1)`                    |
| Дополнителен простор | `O(1)`                    |

Алгоритам:

1. Креирај нов јазол `X`.
2. Запиши ја вредноста `Y` во `DATA(X)`.
3. Провери дали листата е празна:
    - Ако `FIRST = NULL`:
        - Постави `FIRST = X`.
        - Постави `LAST = X`.
        - Постави `LLINK(X) = X`.
        - Постави `RLINK(X) = X`.
    - Во спротивно:
        - Постави `LLINK(X) = LAST`.
        - Постави `RLINK(X) = FIRST`.
        - Постави `RLINK(LAST) = X`.
        - Постави `LLINK(FIRST) = X`.
        - Постави `FIRST = X`.
4. Заврши.

Псевдокод:

```text
procedure INSERT_FIRST(Y)

    create X
    DATA(X) ← Y

    if FIRST = NULL then
        FIRST ← X
        LAST ← X

        LLINK(X) ← X
        RLINK(X) ← X
    else
        LLINK(X) ← LAST
        RLINK(X) ← FIRST

        RLINK(LAST) ← X
        LLINK(FIRST) ← X

        FIRST ← X
    end if

end INSERT_FIRST
```

```text

[bat] ⇄ [cat] ⇄ [dog]

  |___________________|

Вметни: ant

Потоа:

[ant] ⇄ [bat] ⇄ [cat] ⇄ [dog]
```

Ако листата веќе содржи јазли, новиот јазол се поставува меѓу стариот последен и стариот прв јазол. Потоа се ажурираат
врските на двата соседни јазли и покажувачот `first` се поставува да покажува кон новиот јазол.

Бидејќи се користат директните референци `first` и `last`, не е потребно изминување на листата. Затоа временската
сложеност е `O(1)`.

#### Вметнување меѓу два јазли

Цел: Вметнување нов јазол веднаш по определен постоен јазол `CURR`.

| Карактеристика       | Опис                                |
|----------------------|-------------------------------------|
| Предуслов            | Познат е јазолот по кој се вметнува |
| Резултат             | Новиот јазол е вметнат по `CURR`    |

| Дополнителен простор | `O(1)`                              |

Алгоритам:

Да претпоставиме дека сакаме да вметнеме нов јазол `X` по јазолот `CURR`.

1. Креирај нов јазол `X`.
2. Запиши ја вредноста `Y` во `DATA(X)`.
3. Постави `LLINK(X) = CURR`.
4. Постави `RLINK(X) = RLINK(CURR)`.
5. Постави `LLINK(RLINK(CURR)) = X`.
6. Постави `RLINK(CURR) = X`.
7. Ако `CURR = LAST`, постави `LAST = X`.
8. Заврши.

Псевдокод:

```text

    RLINK(X) ← RLINK(CURR)

    end if
```

#### Бришење елемент од листата

Бришењето елемент од двојно поврзана кружна листа се изведува со промена на врските на претходниот и следниот јазол,
така што јазолот што се брише ќе биде исклучен од кружната структура.

При бришење треба да се земат предвид три случаи:

- Листата е празна.
- Листата содржи само еден јазол.
- Листата содржи повеќе јазли.

Дополнително, кога се брише првиот или последниот јазол, мора да се ажурираат `FIRST` или `LAST`.

#### Бришење на првиот јазол

Цел: Отстранување на првиот јазол од листата.

| Карактеристика       | Опис                     |
|----------------------|--------------------------|
| Предуслов            | Листата не е празна      |
| Резултат             | Првиот јазол е отстранет |
| Временска сложеност  | `O(1)`                   |
| Дополнителен простор | `O(1)`                   |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Провери дали листата содржи само еден јазол:
    - Ако `FIRST = LAST`, постави `FIRST = NULL` и `LAST = NULL`.
4. Во спротивно:
    - Постави `FIRST = RLINK(FIRST)`.
    - Постави `LLINK(FIRST) = LAST`.
    - Постави `RLINK(LAST) = FIRST`.
5. Заврши.

```text

    end if

        FIRST ← NULL
        LAST ← NULL
    else

        LLINK(FIRST) ← LAST
        RLINK(LAST) ← FIRST
    end if
```

```java
}
```

Објаснување: Ако листата содржи само еден јазол, неговото бришење ја прави листата празна.

Во спротивно, `last` се поместува на претходниот јазол преку `left`. Потоа неговата врска `right` се поставува да
покажува кон `first`, а `first.left` се ажурира да покажува кон новиот последен јазол.

Бидејќи секој јазол има директна врска кон претходниот, не е потребно изминување на листата. Временската сложеност е
`O(1)`.

#### Бришење средишен јазол

Цел: Отстранување на јазол кој се наоѓа меѓу два други јазли.

| Карактеристика       | Опис                                     |
|----------------------|------------------------------------------|
| Предуслов            | Познат е јазолот што треба да се избрише |
| Резултат             | Јазолот е отстранет                      |
| Временска сложеност  | `O(1)`                                   |
| Дополнителен простор | `O(1)`                                   |

Алгоритам:

Да претпоставиме дека треба да се избрише јазолот `X`.

1. Провери дали `X = NULL`.
2. Ако листата е празна, заврши.
3. Ако листата содржи само еден јазол:
    - Постави `FIRST = NULL`.
    - Постави `LAST = NULL`.
4. Во спротивно:
    - Постави `RLINK(LLINK(X)) = RLINK(X)`.
    - Постави `LLINK(RLINK(X)) = LLINK(X)`.
5. Ако `X = FIRST`, постави `FIRST = RLINK(X)`.
6. Ако `X = LAST`, постави `LAST = LLINK(X)`.
7. Заврши.

Псевдокод:

```text
procedure DELETE_NODE(X)

    if X = NULL then
        return
    end if

    if FIRST = LAST then
        FIRST ← NULL
        LAST ← NULL
    else
        RLINK(LLINK(X)) ← RLINK(X)
        LLINK(RLINK(X)) ← LLINK(X)

        if X = FIRST then
            FIRST ← RLINK(X)
        end if

        if X = LAST then
            LAST ← LLINK(X)
        end if
    end if

end DELETE_NODE
```

Пример:

```text
Пред:

FIRST                                  LAST
  |                                      |
  v                                      v
[ant] ⇄ [bat] ⇄ [cat] ⇄ [dog]
  ^                                      |
  |______________________________________|

X = cat

Избриши го cat.

Потоа:

FIRST                          LAST
  |                              |
  v                              v
[ant] ⇄ [bat] ⇄ [dog]
  ^                              |
  |______________________________|
```

Java имплементација:

```java
public void deleteNode(Node x) {
    if (x == null || first == null) {
        return;
    }

    if (first == last) {
        first = null;
        last = null;
        return;
    }

    x.left.right = x.right;
    x.right.left = x.left;

    if (x == first) {
        first = x.right;
    }

    if (x == last) {
        last = x.left;
    }
}
```

Објаснување: Кај двојно поврзаната листа не е потребно пронаоѓање на претходникот на јазолот што се брише, бидејќи секој
јазол директно ја содржи референцата кон својот претходник.

Прво се поврзува претходниот јазол со следниот јазол, а потоа следниот јазол се поврзува со претходниот.

Ако се брише првиот или последниот јазол, дополнително се ажурираат `first` или `last`.

Ако јазолот е познат, операцијата има временска сложеност `O(1)`.

#### Бришење јазол со определена вредност

Цел: Пронаоѓање и отстранување на првиот јазол што содржи определена вредност `x`.

| Карактеристика       | Опис                                     |
|----------------------|------------------------------------------|
| Предуслов            | Листата е иницијализирана                |
| Резултат             | Јазолот со бараната вредност е отстранет |
| Најдобар случај      | `O(1)`                                   |
| Просечен случај      | `O(n)`                                   |
| Најлош случај        | `O(n)`                                   |
| Дополнителен простор | `O(1)`                                   |

Алгоритам:

1. Провери дали `FIRST = NULL`.
2. Ако листата е празна, заврши.
3. Постави `CURR = FIRST`.
4. Провери дали `DATA(CURR) = x`:
    - Ако е точно, избриши го јазолот и заврши.
5. Премини на следниот јазол преку `RLINK(CURR)`.
6. Повторувај додека `CURR != FIRST`.
7. Ако вредноста е пронајдена:
    - Постави `RLINK(LLINK(CURR)) = RLINK(CURR)`.
    - Постави `LLINK(RLINK(CURR)) = LLINK(CURR)`.
    - Ако `CURR = LAST`, ажурирај го `LAST`.
8. Ако вредноста не е пронајдена, заврши.

Java имплементација:

```java
public void delete(String value) {
    Node curr = search(value);

    if (curr == null) {
        return;
    }

    deleteNode(curr);
}
```

Објаснување: Прво се користи операцијата `search()` за да се пронајде јазолот што ја содржи бараната вредност. Ако
јазолот не постои, листата останува непроменета.

Ако јазолот е пронајден, се повикува `deleteNode()` за негово отстранување.

Вкупната временска сложеност е `O(n)`, бидејќи пребарувањето може да бара проверка на сите јазли. Самото бришење има
сложеност `O(1)`.

#### Бришење на целата листа

Цел: Отстранување на сите јазли од двојно поврзаната кружна листа и нејзино поставување во празна состојба.

| Карактеристика       | Опис                      |
|----------------------|---------------------------|
| Предуслов            | Листата е иницијализирана |
| Резултат             | Празна листа              |
| Временска сложеност  | `O(1)` во Java            |
| Дополнителен простор | `O(1)`                    |

Алгоритам:

1. Постави `FIRST = NULL`.
2. Постави `LAST = NULL`.
3. Заврши.

Java имплементација:

```java
public void clear() {
    first = null;
    last = null;
}
```

Објаснување: Во Java, поставувањето на `first` и `last` на `null` ги отстранува референците на класата кон листата.

Бидејќи јазлите се меѓусебно поврзани во кружна структура, нивните референци може да формираат циклус. Сепак, Java
Garbage Collector може да ги отстрани и објектите што меѓусебно се референцираат, доколку повеќе не се достапни од
активните референци во програмата.

Не е потребно рачно ослободување на меморијата за секој јазол.

Операцијата има временска сложеност `O(1)`, бидејќи се менуваат само две референци.

### Временска сложеност на операциите

Нека `n` го означува бројот на јазли во листата.

| Операција                    | Временска сложеност |
|------------------------------|---------------------|
| Креирање празна листа        | `O(1)`              |
| Изминување нанапред          | `O(n)`              |
| Изминување наназад           | `O(n)`              |
| Пребарување                  | `O(n)`              |
| Вметнување на почеток        | `O(1)`              |
| Вметнување на крај           | `O(1)`              |
| Вметнување по познат јазол   | `O(1)`              |
| Вметнување пред познат јазол | `O(1)`              |
| Бришење на првиот јазол      | `O(1)`              |
| Бришење на последниот јазол  | `O(1)`              |
| Бришење познат јазол         | `O(1)`              |
| Бришење по вредност          | `O(n)`              |
| Бришење на целата листа      | `O(1)` во Java      |

Наведените временски сложености се однесуваат на имплементација која ги одржува двата покажувачи `FIRST` и `LAST`.

Вметнувањето и бришењето на почетокот и на крајот имаат `O(1)` сложеност бидејќи директно се пристапува до соодветните
јазли.

За разлика од еднострано поврзаната листа, кај двојно поврзаната листа бришењето на познат јазол не бара пронаоѓање на
неговиот претходник. Претходникот и следбеникот се директно достапни преку `LLINK` и `RLINK`.

### Просторна сложеност

Ако листата содржи `n` јазли, вкупната просторна сложеност е:

$$
S (n) = \Theta (n)
$$

Секој јазол содржи:

- Едно информациско поле `DATA`.
- Едно покажувачко поле `LLINK`.
- Едно покажувачко поле `RLINK`.

Дополнително, класата `CDLL` содржи два покажувачи:

- `FIRST` – го означува првиот јазол.
- `LAST` – го означува последниот јазол.

Секој јазол зафаќа дополнителна меморија за две врски, за разлика од еднострано поврзаната листа, каде што секој јазол
содржи само една врска.

Помошните покажувачи што се користат при изминување, пребарување, вметнување и бришење заземаат константен дополнителен
простор, односно `O(1)`.

### Предности и недостатоци

Предности:

- Големината на листата може динамички да се менува.
- Не е потребно однапред дефинирање на максималниот број елементи.
- Не е потребно поместување на останатите јазли при вметнување и бришење.
- Секој јазол има директна врска кон претходниот и следниот јазол.
- Можно е изминување во двете насоки.
- Може да се започне со изминување од кој било познат јазол.
- Последниот јазол е поврзан со првиот, а првиот со последниот.
- Вметнувањето на почетокот има сложеност `O(1)`.
- Вметнувањето на крајот има сложеност `O(1)` ако се одржува `LAST`.
- Бришењето на првиот и последниот јазол има сложеност `O(1)`.
- Бришењето познат јазол има сложеност `O(1)`.
- Погодна е за задачи што бараат двонасочно циклично движење низ елементите.

Недостатоци:

- Нема директен пристап до произволен јазол.
- Пребарувањето бара последователно изминување.
- Секој јазол зафаќа дополнителна меморија за две врски.
- Потребно е ажурирање на повеќе врски при вметнување и бришење.
- Потребно е дополнително одржување на `FIRST` и `LAST`.
- Неправилно ажурирање на врските може да ја наруши кружната структура.
- Потребно е посебно внимание при проверка на условите за завршување на изминувањето.
- Поголема е веројатноста за програмски грешки при манипулација со врските во споредба со еднострано поврзаната листа.

## Двострано Поврзани Листи (Doubly Linked Lists — DLL)

### Дефиниција

Двострано поврзана листа (Doubly Linked List — DLL) е динамичка податочна структура составена од јазли кои се поврзани
преку покажувачи или референци.

Секој јазол содржи три полиња:

- `DATA` (`data`) – ја содржи вредноста на јазолот.
- `LLINK` (`prev`) – содржи покажувач или референца кон претходниот јазол.
- `RLINK` (`next`) – содржи покажувач или референца кон следниот јазол.

Класата `DLL` содржи два покажувачи:

- `HEAD` (`head`) – ја означува адресата на првиот јазол.
- `TAIL` (`tail`) – ја означува адресата на последниот јазол.

Пример:

```text
               prev                 prev
                ^                    ^
                |                    |
HEAD            |                    |           TAIL
 |              |                    |             |
 v              v                    v             v
NULL ← [ant] ⇄ [bat] ⇄ [cat] → NULL
        |                |
        +------ next ---+
```

Во двострано поврзаната листа, секој јазол има врска кон својот претходник и кон својот следбеник.

Првиот јазол има `LLINK = NULL`, бидејќи нема претходен јазол.

Последниот јазол има `RLINK = NULL`, бидејќи нема следен јазол.

Празната листа не содржи ниту еден јазол, па затоа:

```text
HEAD = NULL
TAIL = NULL
```

Должината на листата претставува број на јазли што ги содржи. Таа може динамички да се зголемува или намалува во
зависност од достапната меморија.

### Основни својства

- Јазлите се поврзани преку два покажувачи или референци.
- Јазлите не мора да бидат сместени на последователни мемориски локации.
- Листата нема однапред определена максимална големина.
- Почетокот на листата се одредува преку покажувачот `HEAD`.
- Крајот на листата се одредува преку покажувачот `TAIL`.
- Првиот јазол има `LLINK = NULL`.
- Последниот јазол има `RLINK = NULL`.
- Празната листа се означува со `HEAD = NULL` и `TAIL = NULL`.
- Листата може да се изминува во двете насоки.
- Нема директен пристап до произволен јазол, како кај низите.
- За пристап до определен јазол потребно е изминување од почетокот или од крајот на листата.
- Секој јазол, освен првиот, има претходник.
- Секој јазол, освен последниот, има следбеник.
- При вметнување и бришење се менуваат врските меѓу јазлите, без поместување на останатите јазли.
- Вметнувањето на почетокот и на крајот има временска сложеност `O(1)`, доколку се одржуваат `HEAD` и `TAIL`.
- Бришењето на познат јазол има временска сложеност `O(1)`, бидејќи директно се пристапува до неговиот претходник и
  следбеник.

### Основни операции

Над двострано поврзаните листи може да се извршуваат следните операции:

1. Креирање празна листа.
2. Изминување на листата нанапред.
3. Изминување на листата наназад.
4. Пребарување елемент.
5. Вметнување елемент на почетокот.
6. Вметнување елемент на крајот.
7. Вметнување елемент пред даден јазол.
8. Вметнување елемент по даден јазол.
9. Бришење на првиот јазол.
10. Бришење на последниот јазол.
11. Бришење јазол со определена вредност.
12. Бришење познат јазол.
13. Бришење на целата листа.

#### Креирање празна листа

Цел: Иницијализација на празна двострано поврзана листа.

| Карактеристика      | Опис         |
|---------------------|--------------|
| Предуслов           | Нема         |
| Резултат            | Празна листа |
| Временска сложеност | `O(1)`       |
| Просторна сложеност | `O(1)`       |

Алгоритам:

1. Започни.
2. Креирај нова празна листа.
3. Постави го покажувачот `HEAD` на `NULL`.
4. Постави го покажувачот `TAIL` на `NULL`.
5. Заврши.

Пример:

```text
Пред:

Листата не постои.

По иницијализација:

HEAD = NULL
TAIL = NULL
```

Java имплементација:

```java
public class DLL {
    private final Node head;
    private final Node tail;

    public DLL() {
        head = null;
        tail = null;
    }
}
```

Објаснување: При креирање на празна листа, покажувачите `head` и `tail` се поставуваат на `null`. Тоа означува дека
листата не содржи ниту еден јазол.

#### Изминување на листата нанапред

Цел: Да се посетат сите јазли на листата точно по еднаш, почнувајќи од првиот јазол.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Листата е иницијализирана |
| Резултат            | Сите јазли се посетени    |
| Временска сложеност | `O(n)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Постави го тековниот покажувач `CURR` на `HEAD`.
3. Додека `CURR != NULL`:
    - Прочитај ја вредноста `DATA(CURR)`.
    - Изврши ја потребната операција врз тековниот јазол.
    - Премини на следниот јазол преку `RLINK(CURR)`.
4. Заврши кога `CURR` ќе стане `NULL`.
5. Заврши.

Пример:

```text
HEAD
 |
 v
NULL ← [ant] ⇄ [bat] ⇄ [cat] → NULL
                                  ^
                                  |
                                 TAIL

Редослед на посетување:

ant → bat → cat
```

Java имплементација:

```java
public void printForward() {
    Node curr = head;

    while (curr != null) {
        System.out.println(curr.data);
        curr = curr.next;
    }
}
```

Објаснување: Изминувањето започнува од `head`. Со секоја итерација, `curr` се поместува кон следниот јазол преку `next`.
Постапката завршува кога `curr` ќе стане `null`. Секој јазол се посетува точно еднаш, па временската сложеност е `O(n)`.

#### Изминување на листата наназад

Цел: Да се посетат сите јазли на листата точно по еднаш, почнувајќи од последниот јазол.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Листата е иницијализирана |
| Резултат            | Сите јазли се посетени    |
| Временска сложеност | `O(n)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Постави го тековниот покажувач `CURR` на `TAIL`.
3. Додека `CURR != NULL`:
    - Прочитај ја вредноста `DATA(CURR)`.
    - Изврши ја потребната операција врз тековниот јазол.
    - Премини на претходниот јазол преку `LLINK(CURR)`.
4. Заврши кога `CURR` ќе стане `NULL`.
5. Заврши.

Пример:

```text
HEAD                                  TAIL
 |                                      |
 v                                      v
NULL ← [ant] ⇄ [bat] ⇄ [cat] → NULL

Редослед на посетување:

cat → bat → ant
```

Java имплементација:

```java
public void printBackward() {
    Node curr = tail;

    while (curr != null) {
        System.out.println(curr.data);
        curr = curr.prev;
    }
}
```

Објаснување: Изминувањето започнува од `tail`. Со секоја итерација, `curr` се поместува кон претходниот јазол преку
`prev`. Постапката завршува кога `curr` ќе стане `null`. Секој јазол се посетува точно еднаш, па временската сложеност е
`O(n)`.

#### Пребарување елемент

Цел: Да се пронајде јазол кој содржи определена вредност `x`.

| Карактеристика                        | Опис                                           |
|---------------------------------------|------------------------------------------------|
| Предуслов                             | Листата е иницијализирана                      |
| Резултат                              | Пронајден јазол или информација дека не постои |
| Временска сложеност – најдобар случај | `O(1)`                                         |
| Временска сложеност – просечен случај | `O(n)`                                         |
| Временска сложеност – најлош случај   | `O(n)`                                         |
| Просторна сложеност                   | `O(1)`                                         |

Алгоритам:

1. Започни.
2. Прими ја бараната вредност `x`.
3. Постави `CURR = HEAD`.
4. Додека `CURR != NULL`:
    - Провери дали `DATA(CURR) == x`.
    - Ако условот е исполнет, врати го пронајдениот јазол.
    - Во спротивно, премини на следниот јазол преку `RLINK(CURR)`.
5. Ако се стигне до `NULL`, врати `NULL`.
6. Заврши.

Пример:

```text
HEAD → [ant] ⇄ [bat] ⇄ [cat] → NULL

Барана вредност: bat

Резултат:

ant → bat (пронајден)
```

Java имплементација:

```java
public Node search(String value) {
    Node curr = head;

    while (curr != null) {
        if (Objects.equals(curr.data, value)) {
            return curr;
        }

        curr = curr.next;
    }

    return null;
}
```

Објаснување: Пребарувањето започнува од првиот јазол и се врши последователно преку врската `next`. Во најдобар случај,
бараната вредност се наоѓа во првиот јазол. Во најлош случај, се проверуваат сите јазли или елементот воопшто не постои.
Двостраната поврзаност овозможува пребарување и од крајот на листата, но временската сложеност останува `O(n)`.

#### Вметнување елемент на почетокот

Цел: Додавање нов јазол пред моментално првиот јазол на листата.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Листата е иницијализирана |
| Резултат            | Новиот јазол станува прв  |
| Временска сложеност | `O(1)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Прими ја вредноста `Y` што треба да се вметне.
3. Креирај нов јазол `X`.
4. Запиши ја вредноста `Y` во `DATA(X)`.

    - Ако `HEAD = NULL`, постави `TAIL = X`.
    - Во спротивно, постави `LLINK(HEAD) = X`.

```text

                               ^
                              TAIL

 |                                   |
 v                                   v

```

#### Бришење познат јазол

Цел: Отстранување на определен јазол `X` од листата, кога неговата адреса е веќе позната.

| Карактеристика      | Опис                           |
|---------------------|--------------------------------|
| Предуслов           | `X` е валиден јазол во листата |
| Резултат            | Јазолот `X` е отстранет        |
| Временска сложеност | `O(1)` ако `X` е познат        |
| Просторна сложеност | `O(1)`                         |

Алгоритам:

1. Започни.
2. Прими го јазолот `X` што треба да се избрише.
3. Ако `LLINK(X) != NULL`:
    - Постави `RLINK(LLINK(X)) = RLINK(X)`.
4. Во спротивно:
    - Постави `HEAD = RLINK(X)`.
5. Ако `RLINK(X) != NULL`:
    - Постави `LLINK(RLINK(X)) = LLINK(X)`.
6. Во спротивно:
    - Постави `TAIL = LLINK(X)`.
7. Заврши.

Псевдокод:

```text

    IF LLINK(X) != NULL:
        RLINK(LLINK(X)) ← RLINK(X)
    ELSE:
        HEAD ← RLINK(X)

    IF RLINK(X) != NULL:
        LLINK(RLINK(X)) ← LLINK(X)
    ELSE:
        TAIL ← LLINK(X)

end DELETE_NODE
```

Пример:

```text
Пред:

HEAD → [ant] ⇄ [bat] ⇄ [cat] ⇄ [dog] → NULL
                X

Избриши го јазолот bat.

Потоа:

HEAD → [ant] ⇄ [cat] ⇄ [dog] → NULL
```

Java имплементација:

```java
public void delete(Node x) {
    if (x == null) {
        return;
    }

    if (x.prev == null) {
        head = x.next;
    } else {
        x.prev.next = x.next;
    }

    if (x.next == null) {
        tail = x.prev;
    } else {
        x.next.prev = x.prev;
    }
}
```

Објаснување: Ако јазолот има претходник, неговиот претходник се поврзува директно со следбеникот на јазолот што се
брише. Ако нема претходник, тоа значи дека е првиот јазол и `head` се ажурира. Потоа се проверува следбеникот. Ако
постои, неговата врска `prev` се ажурира. Ако не постои, тоа значи дека јазолот е последен и `tail` се ажурира.

За разлика од еднострано поврзаната листа, двострано поврзаната листа овозможува директен пристап до претходникот на
јазолот. Затоа, ако јазолот е однапред познат, неговото бришење има временска сложеност `O(1)`. Ако треба прво да се
пронајде, вкупната сложеност е `O(n)`.

```java
public void clear() {
    head = null;
    tail = null;
}
```

Објаснување: Во Java, поставувањето на `head` и `tail` на `null` ги отстранува почетните референци кон листата. Јазлите
кои повеќе не се достапни од активни референци стануваат подобни за автоматско ослободување преку Garbage Collector.
Затоа не е потребно рачно ослободување на секој јазол. Прикажаната имплементација има временска сложеност `O(1)`.

### Временска сложеност на операциите

Нека `n` го означува бројот на јазли во листата.

| Операција                    | Временска сложеност |
|------------------------------|---------------------|
| Креирање празна листа        | `O(1)`              |
| Изминување нанапред          | `O(n)`              |
| Изминување наназад           | `O(n)`              |
| Пребарување                  | `O(n)`              |
| Вметнување на почеток        | `O(1)`              |
| Вметнување на крај           | `O(1)`              |
| Вметнување пред познат јазол | `O(1)`              |
| Вметнување по познат јазол   | `O(1)`              |
| Бришење на првиот јазол      | `O(1)`              |
| Бришење на последниот јазол  | `O(1)`              |
| Бришење по вредност          | `O(n)`              |
| Бришење познат јазол         | `O(1)`              |
| Бришење на целата листа      | `O(1)` во Java      |

Забелешка: Сложеноста `O(1)` за вметнување пред или по даден јазол и за бришење познат јазол претпоставува дека адресата
на јазолот е веќе позната. Ако јазолот прво треба да се пронајде, вкупната временска сложеност е `O(n)`.

Забелешка: `clear()` во прикажаната Java имплементација има `O(1)` сложеност бидејќи само ги менува двете почетни
референци. Ако се анализира експлицитно отстранување на секој јазол, временската сложеност е `O(n)`.

### Просторна сложеност

Ако листата содржи `n` јазли, вкупната просторна сложеност е:

$$
S (n) = \Theta (n)
$$

Секој јазол содржи:

- Едно информациско поле `DATA`.
- Едно покажувачко поле `LLINK`.
- Едно покажувачко поле `RLINK`.

Дополнително, класата `DLL` содржи два покажувачи:

- `HEAD` – го означува почетокот на листата.
- `TAIL` – го означува крајот на листата.

Помошните покажувачи што се користат при изминување, пребарување, вметнување и бришење заземаат константен дополнителен
простор, односно `O(1)`.

### Предности и недостатоци

Предности:

- Големината на листата може динамички да се менува.
- Не е потребно однапред дефинирање на максималниот број елементи.
- Не е потребно поместување на останатите јазли при вметнување и бришење.
- Овозможува изминување нанапред и наназад.
- Вметнувањето на почетокот има сложеност `O(1)`.
- Вметнувањето на крајот има сложеност `O(1)` кога се чува `TAIL`.
- Бришењето на првиот јазол има сложеност `O(1)`.
- Бришењето на последниот јазол има сложеност `O(1)` кога се чува `TAIL`.
- Вметнувањето пред или по познат јазол има сложеност `O(1)`.
- Бришењето на познат јазол има сложеност `O(1)`, без потреба од пронаоѓање на претходникот.

Недостатоци:

- Нема директен пристап до произволен јазол според индекс.
- Пребарувањето бара последователно изминување на листата.
- Секој јазол зафаќа дополнителна меморија за две врски (`prev` и `next`).
- При вметнување и бришење треба правилно да се ажурираат повеќе врски.
- Имплементацијата е посложена од онаа на еднострано поврзаната листа.
- Неправилно ажурирање на врските може да предизвика неконзистентна структура.
- Потребна е дополнителна меморија за одржување на покажувачите `HEAD` и `TAIL`.

Важна забелешка: Кај еднострано поврзаната листа секој јазол има една врска `LINK`, која покажува кон следниот јазол.
Кај двострано поврзаната листа секој јазол има две врски: `LLINK` и `RLINK`, кои овозможуваат движење во двете насоки.
Кај кружните поврзани листи последниот јазол повторно се поврзува со првиот јазол, наместо неговата врска да биде
`NULL`. Овие структури имаат различна организација и различни алгоритми за работа.
