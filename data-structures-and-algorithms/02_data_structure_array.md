## Низи

### Дефиниција

Низа (Array) е линеарна податочна структура која чува повеќе елементи од ист тип под едно име. Секој елемент има свој
индекс преку кој може директно да се пристапи до него.

- Индексирањето најчесто започнува од 0.
- Ако низата содржи n елементи, индексите се движат од 0 до n - 1.
- Големината на низата се дефинира при нејзиното креирање и не се менува.
- Елементите се подредени по редослед и се достапни преку индекси.
- Пристапот до елемент според неговиот индекс има временска сложеност O (1).

Пример:

```java
int[] a = {10, 20, 30, 40, 50};
```

| Индекс   | 0  | 1  | 2  | 3  | 4  |
|----------|----|----|----|----|----|
| Вредност | 10 | 20 | 30 | 40 | 50 |

`a[2]` ја враќа вредноста `30`.

### Основни својства на низи

- Подреденост: секој елемент има определена позиција, претставена со индекс.
- Последователно сместување: елементите се сместени во последователни мемориски локации.
- Фиксен капацитет: големината на низата се определува при нејзиното креирање и не може да се менува.
- Директен пристап: пристапот до елемент според индекс има константна временска сложеност `O(1)`.
- Ефикасно изминување: елементите можат да се посетуваат последователно.
- Поместување на елементи: вметнувањето или бришењето во почетокот или средината може да бара поместување на повеќе
  елементи.
- Должина: бројот на елементи што моментално се чуваат во низата.

### Основни операции врз низи

Основните операции врз низите се:

1. Пристап до елемент – добивање вредност според индекс.
2. Изминување на низата – последователно посетување на сите елементи.
3. Пресметување збир – собирање на вредностите на сите елементи.
4. Линеарно пребарување – пребарување елемент со проверка на секоја позиција.
5. Бинарно пребарување – пребарување во сортирана низа со делење на интервалот на половини.
6. Сортирање – подредување на елементите според одреден редослед.
7. Вметнување на почетокот – додавање елемент на првата позиција.
8. Вметнување на определена позиција – додавање елемент на избран индекс.
9. Вметнување на крајот – додавање елемент на последната позиција.
10. Бришење од почетокот – отстранување на првиот елемент.
11. Бришење од определена позиција – отстранување елемент од избран индекс.
12. Бришење од крајот – отстранување на последниот елемент.

#### Пристап до елемент според индекс

Цел: Читање на вредноста на елементот на определен индекс.

| Карактеристика      | Опис                                 |
|---------------------|--------------------------------------|
| Предуслов           | `0 ≤ i < n`                          |
| Резултат            | Вредноста на елементот на индекс `i` |
| Временска сложеност | `O(1)`                               |
| Просторна сложеност | `O(1)`                               |

Алгоритам:

1. Започни.
2. Прими низа `a` и индекс `i`.
3. Провери дали индексот е валиден (`0 ≤ i < n`).
4. Ако индексот не е валиден, пријави грешка.
5. Пристапи до елементот `a[i]`.
6. Прочитај ја вредноста на елементот.
7. Врати ја вредноста.
8. Заврши.

Java имплементација:

```java
int value = a[i];
```

Објаснување: Елементот се добива директно преку индексот, без потреба од пребарување низ останатите елементи.

#### Изминување на низата

Цел: Да се посетат сите елементи на низата по еднаш.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | Низата е иницијализирана  |
| Резултат            | Сите елементи се посетени |
| Временска сложеност | `O(n)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Постави го индексот на `0`.
3. Додека индексот е помал од должината `n`:
    - Прочитај го тековниот елемент.
    - Изврши ја потребната операција врз елементот.
    - Зголеми го индексот за еден.
4. Повторувај додека не се посетат сите елементи.
5. Заврши.

Пример:

```text
Низа: [10, 20, 30, 40]

Редослед на посетување:
10 → 20 → 30 → 40
```

Java имплементација:

```java
void print(int[] a) {
    for (int i = 0; i < a.length; i++) {
        System.out.println(a[i]);
    }
}
```

Објаснување: Секој елемент се посетува точно еднаш, па бројот на операции е пропорционален со бројот на елементи во
низата.

#### Пресметување збир

Цел: Да се пресмета збирот на сите елементи во низата.

| Карактеристика      | Опис                     |
|---------------------|--------------------------|
| Предуслов           | Низата е иницијализирана |
| Резултат            | Збирот на сите елементи  |
| Временска сложеност | `O(n)`                   |
| Просторна сложеност | `O(1)`                   |

Алгоритам:

1. Започни.
2. Иницијализирај ја сумата со `0`.
3. Измини ја низата од првиот до последниот елемент.
4. Додај ја вредноста на секој елемент во сумата.
5. Врати ја добиената сума.
6. Заврши.

Пример:

```text
Низа: [10, 20, 30, 40]

Сума = 0
Сума = 0 + 10 = 10
Сума = 10 + 20 = 30
Сума = 30 + 30 = 60
Сума = 60 + 40 = 100

Резултат: 100
```

Java имплементација:

```java
int getSum() {
    int sum = 0;

    for (int i = 0; i < a.length; i++) {
        sum += a[i];
    }

    return sum;
}
```

Објаснување: Секој елемент мора да се прочита еднаш за да се пресмета точниот збир.

#### Линеарно пребарување

Цел: Да се пронајде индексот на елемент што има определена вредност `x`.

| Карактеристика               | Опис                                                 |
|------------------------------|------------------------------------------------------|
| Предуслов                    | Низата не мора да биде сортирана                     |
| Резултат                     | Индексот на првото појавување или `-1` ако не постои |
| Најдобра временска сложеност | `O(1)`                                               |
| Просечна временска сложеност | `O(n)`                                               |
| Најлоша временска сложеност  | `O(n)`                                               |
| Просторна сложеност          | `O(1)`                                               |

Алгоритам:

1. Започни.
2. Прими низа `a` и вредност `x` што треба да се пронајде.
3. Постави го индексот на `0`.
4. Додека индексот е помал од должината `n`:
    - Спореди ја вредноста на тековниот елемент со `x`.
    - Ако вредностите се еднакви, врати го индексот.
    - Во спротивно, премини на следниот елемент.
5. Ако се стигне до крајот без пронаоѓање, врати `-1`.
6. Заврши.

Пример:

```text
Низа: [10, 20, 30, 40, 50]
Барана вредност: 30

Проверка:
10 ≠ 30
20 ≠ 30
30 = 30

Резултат: индекс 2
```

Java имплементација:

```java
int search(int[] a, int x) {
    for (int i = 0; i < a.length; i++) {
        if (a[i] == x) {
            return i;
        }
    }

    return -1;
}
```

Објаснување: Елементите се проверуваат еден по еден сè додека не се пронајде бараната вредност или не се достигне крајот
на низата.

#### Бинарно пребарување

Цел: Да се пронајде определена вредност во сортирана низа.

| Карактеристика               | Опис                                                    |
|------------------------------|---------------------------------------------------------|
| Предуслов                    | Низата мора да биде сортирана                           |
| Резултат                     | Индексот на пронајдениот елемент или `-1` ако не постои |
| Најдобра временска сложеност | `O(1)`                                                  |
| Просечна временска сложеност | `O(log n)`                                              |
| Најлоша временска сложеност  | `O(log n)`                                              |
| Просторна сложеност          | `O(1)`                                                  |

Алгоритам:

1. Започни.
2. Прими низа `a` и вредност `x` што треба да се пронајде.
3. Постави ја левата граница `low = 0`.
4. Постави ја десната граница `high = n - 1`.
5. Додека `low ≤ high`:
    - Пресметај ја средишната позиција `mid = low + (high - low) / 2`.
    - Ако `a[mid] == x`, врати го индексот `mid`.
    - Ако `x < a[mid]`, постави `high = mid - 1`.
    - Во спротивно, постави `low = mid + 1`.
6. Ако интервалот стане празен, врати `-1`.
7. Заврши.

Пример:

```text
Низа: [10, 20, 30, 40, 50]
Барана вредност: 40

Средишен елемент: 30
40 > 30 → пребарувај десно

Нов средишен елемент: 40
40 = 40

Резултат: индекс 3
```

Java имплементација:

```java
int search(int[] a, int x) {
    int low = 0;
    int high = a.length - 1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (a[mid] == x) {
            return mid;
        } else if (x < a[mid]) {
            high = mid - 1;
        } else {
            low = mid + 1;
        }
    }

    return -1;
}
```

Објаснување: Во секој чекор се отфрла половина од преостанатиот интервал за пребарување, со што значително се намалува
бројот на потребни проверки.

#### Сортирање

Цел: Да се подредат елементите според определен редослед, растечки или опаѓачки.

| Карактеристика               | Опис                     |
|------------------------------|--------------------------|
| Предуслов                    | Низата е иницијализирана |
| Резултат                     | Сортирана низа           |
| Најдобра временска сложеност | `O(n²)`                  |
| Просечна временска сложеност | `O(n²)`                  |
| Најлоша временска сложеност  | `O(n²)`                  |
| Просторна сложеност          | `O(1)`                   |

Алгоритам – Bubble Sort:

1. Започни.
2. Започни со првото поминување низ низата.
3. Спореди ги соседните елементи.
4. Ако се во погрешен редослед, замени им ги местата.
5. Продолжи со споредување на следните соседни елементи.
6. Заврши го поминувањето низ низата.
7. Повторувај ги поминувањата додека не се подредат сите елементи.
8. Заврши.

Пример:

```text
Почетна низа: [5, 2, 4, 1]

Сортирана низа: [1, 2, 4, 5]
```

Java имплементација:

```java
void bubbleSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        for (int j = 0; j < a.length - 1 - i; j++) {
            if (a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
}
```

Објаснување: Соседните елементи се споредуваат и се заменуваат доколку не се во правилен редослед. По секое поминување,
најголемиот од преостанатите несортирани елементи се поставува на својата конечна позиција.

#### Вметнување на почетокот

Цел: Да се додаде нов елемент на првата позиција во низата.

| Карактеристика      | Опис                         |
|---------------------|------------------------------|
| Предуслов           | Низата има слободна позиција |
| Резултат            | Нов елемент на индекс `0`    |
| Временска сложеност | `O(n)`                       |
| Просторна сложеност | `O(1)`                       |

Алгоритам:

1. Започни.
2. Провери дали низата има слободен капацитет.
3. Започни од последниот постоен елемент.
4. Поместувај ги елементите за една позиција надесно.
5. Продолжи сè додека не се ослободи индексот `0`.
6. Запиши ја новата вредност на индекс `0`.
7. Зголеми ја должината за еден.
8. Заврши.

Пример:

```text
Пред:   [10, 20, 30, 40]
Вметни: 5
Потоа:  [5, 10, 20, 30, 40]
```

Java имплементација:

```java
void insertFirst(int[] a, int value, int length) {
    if (length >= a.length) {
        System.out.println("Array is full!");
        return;
    }

    for (int i = length; i > 0; i--) {
        a[i] = a[i - 1];
    }

    a[0] = value;
}
```

Објаснување: За да се ослободи првата позиција, сите постојни елементи мора да се поместат за едно место надесно.

#### Вметнување на определена позиција

Цел: Да се вметне нов елемент на определен индекс `p`.

| Карактеристика               | Опис                                |
|------------------------------|-------------------------------------|
| Предуслов                    | `0 ≤ p ≤ n` и има слободна позиција |
| Резултат                     | Нов елемент на индекс `p`           |
| Најдобра временска сложеност | `O(1)`                              |
| Најлоша временска сложеност  | `O(n)`                              |
| Просторна сложеност          | `O(1)`                              |

Алгоритам:

1. Започни.
2. Провери дали позицијата `p` е валидна.
3. Провери дали низата има слободен капацитет.
4. Започни од последниот постоен елемент.
5. Поместувај ги елементите надесно за една позиција додека не се ослободи позицијата `p`.
6. Запиши ја новата вредност на индекс `p`.
7. Зголеми ја должината за еден.
8. Заврши.

Пример:

text

```text
Пред:      [10, 20, 40, 50]
Позиција:  2
Вредност:  30
Потоа:     [10, 20, 30, 40, 50]
```

Java имплементација:

java

```java
void insert(int[] a, int value, int at, int length) {
    if (length >= a.length) {
        System.out.println("Array is full!");
        return;
    }

    if (at < 0 || at > length) {
        System.out.println("Invalid index!");
        return;
    }

    for (int i = length; i > at; i--) {
        a[i] = a[i - 1];
    }

    a[at] = value;
}
```

Објаснување: Елементите од позицијата `p` па натаму се поместуваат за едно место надесно за да се ослободи местото за
новиот елемент.

#### Вметнување на крајот

Цел: Да се додаде нов елемент по последниот постоен елемент.

| Карактеристика      | Опис                               |
|---------------------|------------------------------------|
| Предуслов           | Низата има слободна позиција       |
| Резултат            | Нов елемент на последната позиција |
| Временска сложеност | `O(1)`                             |
| Просторна сложеност | `O(1)`                             |

Алгоритам:

1. Започни.
2. Провери дали низата има слободен капацитет.
3. Запиши ја новата вредност на индекс `n`.
4. Зголеми ја должината за еден.
5. Заврши.

Пример:

```text
Пред:   [10, 20, 30]
Вметни: 40
Потоа:  [10, 20, 30, 40]
```

Java имплементација:

```java
int insertLast(int[] a, int value, int length) {
    if (length >= a.length) {
        System.out.println("Array is full!");
        return;
    }

    a[length] = value;

    return length + 1;
}
```

Објаснување: Новиот елемент се додава на следната слободна позиција, без потреба од поместување на постојните елементи.

#### Бришење од почетокот

Цел: Да се отстрани првиот елемент од низата.

| Карактеристика      | Опис                       |
|---------------------|----------------------------|
| Предуслов           | Низата не е празна         |
| Резултат            | Првиот елемент е отстранет |
| Временска сложеност | `O(n)`                     |
| Просторна сложеност | `O(1)`                     |

Алгоритам:

1. Започни.
2. Провери дали низата е празна.
3. Помести ги сите елементи за една позиција налево, почнувајќи од индекс `1`.
4. Продолжи до последниот постоен елемент.
5. Намали ја должината за еден.
6. Заврши.

Пример:

```text
Пред:   [10, 20, 30, 40]
Потоа:  [20, 30, 40]
```

Java имплементација:

```java
int deleteFirst(int[] a, int length) {
    if (length == 0) {
        System.out.println("Array is empty!");
        return length;
    }

    for (int i = 0; i < length - 1; i++) {
        a[i] = a[i + 1];
    }

    return length - 1;
}
```

Објаснување: По бришењето на првиот елемент, останатите елементи се поместуваат налево за да се зачува нивниот редослед.

#### Бришење од определена позиција

Цел: Да се отстрани елементот на определен индекс `p`.

| Карактеристика               | Опис                                |
|------------------------------|-------------------------------------|
| Предуслов                    | `0 ≤ p < n`                         |
| Резултат                     | Елементот на индекс `p` е отстранет |
| Најдобра временска сложеност | `O(1)`                              |
| Најлоша временска сложеност  | `O(n)`                              |
| Просторна сложеност          | `O(1)`                              |

Алгоритам:

1. Започни.
2. Провери дали позицијата `p` е валидна.
3. Поместувај ги елементите десно од `p` за една позиција налево.
4. Продолжи до последниот постоен елемент.
5. Намали ја должината за еден.
6. Заврши.

Пример:

```text
Пред:      [10, 20, 30, 40, 50]
Позиција:  2
Потоа:     [10, 20, 40, 50]
```

Java имплементација:

```java
int deleteAt(int[] a, int length, int p) {
    if (p < 0 || p >= length) {
        System.out.println("Invalid index!");
        return length;
    }

    for (int i = p; i < length - 1; i++) {
        a[i] = a[i + 1];
    }

    return length - 1;
}
```

Објаснување: Елементите по позицијата `p` се поместуваат налево за да се пополни празното место.

#### Бришење од крајот

Цел: Да се отстрани последниот елемент од низата.

| Карактеристика      | Опис                           |
|---------------------|--------------------------------|
| Предуслов           | Низата не е празна             |
| Резултат            | Последниот елемент е отстранет |
| Временска сложеност | `O(1)`                         |
| Просторна сложеност | `O(1)`                         |

Алгоритам:

1. Започни.
2. Провери дали низата е празна.
3. Намали ја должината за еден.
4. Заврши.

Пример:

```text
Пред:   [10, 20, 30, 40]
Потоа:  [10, 20, 30]
```

Java имплементација:

```java
int deleteLast(int[] a, int length) {
    if (length == 0) {
        System.out.println("Array is empty!");
        return length;
    }

    return length - 1;
}
```

Објаснување: Последниот елемент повеќе не се смета за дел од низата. Не е потребно поместување на останатите елементи.

### Предности и недостатоци

Предности:

- Директен пристап до елементите според индекс во `O(1)` време.
- Ефикасно изминување на елементите.
- Последователното сместување овозможува ефикасно користење на меморијата.
- Едноставна структура и лесна имплементација.

Недостатоци:

- Фиксна големина кај класичните низи.
- Вметнувањето на почетокот или во средината бара поместување на елементите.
- Бришењето од почетокот или од средината бара поместување на елементите.
- Пребарувањето без сортирана низа може да бара проверка на сите елементи.

Важна напомена за Java: Низата мора однапред да има доволен капацитет. Java низите имаат фиксна големина, па овие
примери претпоставуваат дека има слободно место за вметнување. Исто така, додавањето и бришењето ја менува логичката
должина, но не ја намалува физичката големина на низата.

## Динамички низи

### Дефиниција

**Динамичка низа (dynamic array)** е податочна структура што користи внатрешна низа и овозможува бројот на елементи да
се менува во текот на извршувањето.

За разлика од класичната фиксна низа, динамичката низа може автоматски да го зголеми капацитетот кога нема доволно
простор за нов елемент. Кога капацитетот ќе се исполни, се создава поголема внатрешна низа и постојните елементи се
копираат во неа. Вообичаена пракса е новиот капацитет да биде (1.5 - 2) пати поголем од претходниот капацитет.

Нека:

- `n` е моменталната должина;
- `C` е капацитетот.

Важи: `0 ≤ n ≤ C`

**Примери:** `vector` во C++ и `ArrayList` во Java.

### Основни својства на динамички низи

- Пристапот до елемент според индекс е `O(1)`.
- Капацитетот може да биде поголем од моменталната должина.
- Кога капацитетот ќе се исполни, се алоцира поголема внатрешна низа.
- Проширувањето обично вклучува копирање на постојните елементи.
- Поединечното додавање на крајот може да биде `O(n)` ако е потребно проширување.
- Додавањето на крајот е амортизирано `O(1)` бидејќи капацитетот обично се удвојува, со што се намалува бројот на
  проширувања и копирања.
- Капацитетот се удвојува како компромис меѓу бројот на копирања и потрошувачката на меморија.
- Зголемувањето за еден елемент би предизвикало чести копирања, додека многу поголем пораст би можел да потроши
  непотребно многу меморија.
- Удвојувањето не е задолжително правило; може да се користи и друг фактор на раст.
- Вметнувањето и бришењето на почетокот или во средината може да бараат поместување на елементите.

**Важно разграничување:** Динамичката низа автоматски управува со капацитетот, но не ги прави сите операции `O(1)`.
Вметнувањето или бришењето во средината и понатаму може да бара поместување на `O(n)` елементи.

### Основни операции врз динамички низи

Основните операции врз динамичките низи се:

1. Пристап до елемент – добивање вредност според индекс.
2. Изминување на динамичката низа – последователно посетување на сите елементи.
3. Линеарно пребарување – пребарување елемент со проверка на секоја позиција.
4. Вметнување на почетокот – додавање елемент на првата позиција.
5. Вметнување на определена позиција – додавање елемент на избран индекс.
6. Вметнување на крајот со слободен капацитет – додавање елемент без проширување.
7. Вметнување на крајот со проширување – додавање елемент со зголемување на капацитетот.
8. Бришење од почетокот – отстранување на првиот елемент.
9. Бришење од определена позиција – отстранување елемент од избран индекс.
10. Бришење од крајот – отстранување на последниот елемент.

#### Пристап до елемент според индекс

Цел: Читање на вредноста на елементот на определен индекс.

| Карактеристика      | Опис                                 |
|---------------------|--------------------------------------|
| Предуслов           | `0 ≤ i < n`                          |
| Резултат            | Вредноста на елементот на индекс `i` |
| Временска сложеност | `O(1)`                               |
| Просторна сложеност | `O(1)`                               |

Алгоритам:

1. Започни.
2. Прими динамичка низа `a` и индекс `i`.
3. Провери дали индексот е валиден.
4. Ако индексот не е валиден, пријави грешка.
5. Пристапи до елементот `a[i]`.
6. Прочитај ја вредноста на елементот.
7. Врати ја вредноста.
8. Заврши.

Java имплементација:

```java
int get(int[] a, int length, int i) {
    if (i < 0 || i >= length) {
        throw new IndexOutOfBoundsException();
    }

    return a[i];
}
```

Објаснување: Елементот се добива директно преку индексот. Бидејќи динамичката низа користи внатрешна низа, пристапот до
елемент е константна операција.

#### Изминување на динамичката низа

Цел: Да се посетат сите елементи на динамичката низа по еднаш.

| Карактеристика      | Опис                               |
|---------------------|------------------------------------|
| Предуслов           | Динамичката низа е иницијализирана |
| Резултат            | Сите постојни елементи се посетени |
| Временска сложеност | `O(n)`                             |
| Просторна сложеност | `O(1)`                             |

Алгоритам:

1. Започни.
2. Постави го индексот на `0`.
3. Додека индексот е помал од логичката должина `n`:
    - Прочитај го тековниот елемент.
    - Изврши ја потребната операција врз елементот.
    - Зголеми го индексот за еден.
4. Повторувај додека не се посетат сите елементи.
5. Заврши.

Пример:

```text
Динамичка низа: [10, 20, 30, 40]

Редослед на посетување:

10 → 20 → 30 → 40
```

Java имплементација:

```java
void print(int[] a, int length) {
    for (int i = 0; i < length; i++) {
        System.out.println(a[i]);
    }
}
```

Објаснување: Се користи `for` циклус за последователно посетување на сите елементи. Се користи `length`, а не
`a.length`, бидејќи капацитетот може да биде поголем од бројот на постојни елементи.

#### Линеарно пребарување

Цел: Да се пронајде елемент со определена вредност `x` во динамичката низа.

| Карактеристика               | Опис                                      |
|------------------------------|-------------------------------------------|
| Предуслов                    | Динамичката низа е иницијализирана        |
| Резултат                     | Индексот на пронајдениот елемент или `-1` |
| Најдобра временска сложеност | `O(1)`                                    |
| Просечна временска сложеност | `O(n)`                                    |
| Најлоша временска сложеност  | `O(n)`                                    |
| Просторна сложеност          | `O(1)`                                    |

Алгоритам:

1. Започни.
2. Прими динамичка низа `a` и вредност `x`.
3. Започни од индексот `0`.
4. Спореди ја вредноста на тековниот елемент со `x`.
5. Ако се еднакви, врати го индексот.
6. Во спротивно, премини на следниот елемент.
7. Ако вредноста не се пронајде, врати `-1`.
8. Заврши.

Пример:

```text
Низа:       [10, 20, 30, 40]
Бараме:     30
Резултат:   2
```

Java имплементација:

```java
int search(int[] a, int length, int x) {
    for (int i = 0; i < length; i++) {
        if (a[i] == x) {
            return i;
        }
    }

    return -1;
}
```

Објаснување: Се проверува секој елемент од почетокот на низата. Ако вредноста се пронајде, се враќа нејзиниот индекс.
Ако не се пронајде, се враќа `-1`.

#### Вметнување на почетокот

Цел: Да се додаде нов елемент на првата позиција во динамичката низа.

| Карактеристика      | Опис                                                   |
|---------------------|--------------------------------------------------------|
| Предуслов           | Постои слободен капацитет или е овозможено проширување |
| Резултат            | Нов елемент на индекс `0`                              |
| Временска сложеност | `O(n)`                                                 |
| Просторна сложеност | `O(1)` без проширување, `O(n)` при проширување         |

Алгоритам:

1. Започни.
2. Провери дали динамичката низа има слободен капацитет.
3. Ако низата е полна, прошири го капацитетот.
4. Започни од последниот постоен елемент.
5. Поместувај ги елементите за една позиција надесно.
6. Запиши ја новата вредност на индекс `0`.
7. Зголеми ја должината за еден.
8. Заврши.

Пример:

```text
Пред:   [10, 20, 30]
Вметни: 5
Потоа:  [5, 10, 20, 30]
```

Java имплементација:

```java
int insertFirst(int[] a, int length, int value) {
    for (int i = length; i > 0; i--) {
        a[i] = a[i - 1];
    }

    a[0] = value;

    return length + 1;
}
```

Објаснување: Сите постојни елементи се поместуваат за една позиција надесно за да се ослободи индексот `0`. Потоа се
запишува новата вредност и се зголемува логичката должина.

Напомена: Функцијата претпоставува дека постои слободна позиција. Ако низата е полна, потребно е претходно проширување.

#### Вметнување на определена позиција

Цел: Да се вметне нов елемент на определен индекс `p` во динамичката низа.

| Карактеристика               | Опис                                                                 |
|------------------------------|----------------------------------------------------------------------|
| Предуслов                    | `0 ≤ p ≤ n` и постои слободен капацитет или е овозможено проширување |
| Резултат                     | Нов елемент на индекс `p`                                            |
| Најдобра временска сложеност | `O(1)`                                                               |
| Најлоша временска сложеност  | `O(n)`                                                               |
| Просторна сложеност          | `O(1)` без проширување, `O(n)` при проширување                       |

Алгоритам:

1. Започни.
2. Провери дали позицијата `p` е валидна.
3. Провери дали динамичката низа има слободен капацитет.
4. Ако низата е полна, прошири го капацитетот.
5. Започни од последниот постоен елемент.
6. Поместувај ги елементите надесно до позицијата `p`.
7. Запиши ја новата вредност на индекс `p`.
8. Зголеми ја должината за еден.
9. Заврши.

Пример:

```text
Пред:      [10, 20, 40, 50]
Позиција:  2
Вредност:  30
Потоа:     [10, 20, 30, 40, 50]
```

Java имплементација:

```java
int insertAt(int[] a, int length, int p, int value) {
    if (p < 0 || p > length) {
        throw new IndexOutOfBoundsException();
    }

    for (int i = length; i > p; i--) {
        a[i] = a[i - 1];
    }

    a[p] = value;

    return length + 1;
}
```

Објаснување: Елементите од позицијата `p` па натаму се поместуваат за едно место надесно. На тој начин се ослободува
позицијата за новиот елемент. Најдобриот случај е кога се вметнува на крајот, бидејќи не е потребно поместување.

Напомена: Функцијата претпоставува дека постои слободен капацитет. Ако низата е полна, потребно е претходно проширување.

#### Додавање на крајот кога има слободен капацитет

Цел: Да се додаде нов елемент на крајот на динамичката низа без проширување на внатрешната низа.

| Карактеристика      | Опис                      |
|---------------------|---------------------------|
| Предуслов           | `n < C`                   |
| Резултат            | Нов елемент на индекс `n` |
| Временска сложеност | `O(1)`                    |
| Просторна сложеност | `O(1)`                    |

Алгоритам:

1. Започни.
2. Провери дали постои слободен капацитет.
3. Запиши ја новата вредност на индекс `n`.
4. Зголеми ја должината за еден.
5. Заврши.

Пример:

```text
Должина: 3
Капацитет: 5

Пред:  [10, 20, 30, _, _]
Додај: 40
Потоа: [10, 20, 30, 40, _]

Нова должина: 4
Капацитет: 5
```

Java имплементација:

```java
int insertLast(int[] a, int length, int value) {
    if (length >= a.length) {
        throw new IllegalStateException("Array is full!");
    }

    a[length] = value;

    return length + 1;
}
```

Објаснување: Новиот елемент се запишува на првата слободна позиција. Бидејќи веќе постои слободен капацитет, не е
потребно копирање или поместување на постојните елементи.

#### Додавање на крајот кога е потребно проширување

Цел: Да се додаде нов елемент на крајот кога динамичката низа нема слободен капацитет.

| Карактеристика      | Опис                                                            |
|---------------------|-----------------------------------------------------------------|
| Предуслов           | `n = C`                                                         |
| Резултат            | Динамичка низа со еден дополнителен елемент и поголем капацитет |
| Временска сложеност | `O(n)` за конкретното проширување                               |
| Просторна сложеност | `O(n)` привремен дополнителен простор                           |

Алгоритам:

1. Започни.
2. Провери дали низата е полна.
3. Одреди нов капацитет, најчесто двојно поголем од тековниот.
4. Алоцирај нова внатрешна низа.
5. Копирај ги сите постојни елементи во новата низа.
6. Запиши го новиот елемент на индекс `n`.
7. Зголеми ја должината за еден.
8. Замени ја старата внатрешна низа со новата.
9. Ажурирај го капацитетот.
10. Заврши.

Пример:

```text
Пред:
Должина: 3
Капацитет: 3

[10, 20, 30]

Проширување:
Нов капацитет: 6

Потоа:
Должина: 4
Капацитет: 6

[10, 20, 30, 40, _, _]
```

Java имплементација:

```java
int[] insertLast(int[] a, int length, int value) {
    if (length == a.length) {
        int newCapacity = (a.length == 0) ? 1 : a.length * 2;

        int[] temp = new int[newCapacity];

        System.arraycopy(a, 0, temp, 0, length);

        a = temp;
    }

    a[length] = value;

    return a;
}
```

Објаснување: Кога низата е полна, се создава нова низа со поголем капацитет. Постојните елементи се копираат во неа, а
новиот елемент се додава на крајот.

Напомена: Оваа функција враќа нова низа, но не и нова логичка должина. За целосна имплементација на динамичка низа,
должината и капацитетот треба да се чуваат заедно со внатрешната низа.

#### Бришење од почетокот

Цел: Да се отстрани првиот елемент од динамичката низа.

| Карактеристика      | Опис                       |
|---------------------|----------------------------|
| Предуслов           | `n > 0`                    |
| Резултат            | Првиот елемент е отстранет |
| Временска сложеност | `O(n)`                     |
| Просторна сложеност | `O(1)`                     |

Алгоритам:

1. Започни.
2. Провери дали низата е празна.
3. Поместувај ги елементите за една позиција налево, почнувајќи од индекс `1`.
4. Продолжи до последниот постоен елемент.
5. Намали ја должината за еден.
6. Заврши.

Пример:

```text
Пред:   [10, 20, 30, 40]
Потоа:  [20, 30, 40]
```

Java имплементација:

```java
int deleteFirst(int[] a, int length) {
    if (length == 0) {
        throw new IllegalStateException("Array is empty!");
    }

    for (int i = 0; i < length - 1; i++) {
        a[i] = a[i + 1];
    }

    return length - 1;
}
```

Објаснување: Првиот елемент се отстранува логички, а останатите елементи се поместуваат за една позиција налево.
Функцијата ја враќа новата логичка должина.

#### Бришење од определена позиција

Цел: Да се отстрани елементот на определен индекс `p` од динамичката низа.

| Карактеристика               | Опис                                |
|------------------------------|-------------------------------------|
| Предуслов                    | `0 ≤ p < n`                         |
| Резултат                     | Елементот на индекс `p` е отстранет |
| Најдобра временска сложеност | `O(1)`                              |
| Најлоша временска сложеност  | `O(n)`                              |
| Просторна сложеност          | `O(1)`                              |

Алгоритам:

1. Започни.
2. Провери дали позицијата `p` е валидна.
3. Поместувај ги елементите десно од `p` за една позиција налево.
4. Продолжи до последниот постоен елемент.
5. Намали ја должината за еден.
6. Заврши.

Пример:

```text
Пред:      [10, 20, 30, 40, 50]
Позиција:  2
Потоа:     [10, 20, 40, 50]
```

Java имплементација:

```java
int deleteAt(int[] a, int length, int p) {
    if (p < 0 || p >= length) {
        throw new IndexOutOfBoundsException();
    }

    for (int i = p; i < length - 1; i++) {
        a[i] = a[i + 1];
    }

    return length - 1;
}
```

Објаснување: Елементите по позицијата `p` се поместуваат за едно место налево за да се пополни празното место.
Најдобриот случај е кога се брише последниот елемент, бидејќи не е потребно поместување.

#### Бришење од крајот

Цел: Да се отстрани последниот елемент од динамичката низа.

| Карактеристика      | Опис                           |
|---------------------|--------------------------------|
| Предуслов           | `n > 0`                        |
| Резултат            | Последниот елемент е отстранет |
| Временска сложеност | `O(1)`                         |
| Просторна сложеност | `O(1)`                         |

Алгоритам:

1. Започни.
2. Провери дали низата е празна.
3. Намали ја должината за еден.
4. Последниот елемент повеќе не го сметај за дел од низата.
5. Заврши.

Пример:

```text
Пред:   [10, 20, 30, 40]
Потоа:  [10, 20, 30]
```

Java имплементација:

```java
int deleteLast(int[] a, int length) {
    if (length == 0) {
        throw new IllegalStateException("Array is empty!");
    }

    return length - 1;
}
```

Објаснување: Последниот елемент се отстранува со намалување на логичката должина за еден. Не е потребно поместување на
останатите елементи, ниту промена на капацитетот.

### Предности и недостатоци

**Предности:**

- Пристапот според индекс останува `O(1)`.
- Големината може да се менува во текот на извршувањето.
- Додавањето на крајот е амортизирано Θ (1) кога капацитетот се удвојува при негово исполнување.
- Не е потребно однапред да се знае точниот број елементи.

**Недостатоци:**

- Проширувањето може да бара `O(n)` време.
- При проширување може да биде потребна дополнителна привремена меморија.
- Вметнувањето и бришењето во почетокот или средината бараат поместување.
- Резервираниот капацитет може да биде поголем од моменталната должина.

## N-димензионални низи

### Дефиниција

**N-димензионална низа** е податочна структура чии елементи се организирани во една или повеќе димензии и се адресираат
со соодветен број индекси.

**Матрица** е дводимензионална низа организирана во редици и колони. Елементот се означува со `A[i][j]`, каде што `i` е
индексот на редицата, а `j` е индексот на колоната.

Матрица со `m` редици и `n` колони се означува со `m × n` и содржи вкупно `m × n` елементи.

**Пример:**

```text
A = [
    [1, 2, 3],
    [4, 5, 6]
]
```

Матрицата има две редици и три колони, односно вкупно шест елементи.

Ако бројот на редици е еднаков на бројот на колони (`m = n`), матрицата е **квадратна матрица**. Квадратна матрица со
`n` редици и `n` колони содржи `n²` елементи.

**Повеќедимензионална низа** е низа чии елементи се адресираат со два или повеќе индекси. Матрицата е дводимензионална
низа, додека низите со три или повеќе димензии се адресираат со соодветен број индекси. На пример, елемент на
тридимензионална низа се означува со `A[i][j][k]`.

### Основни својства на матрици

- Елементите на матрицата се адресираат со два индекса.
- Пристапот до еден елемент е `O(1)` во вообичаена репрезентација со директен пристап.
- Целосното изминување на матрица со `m` редици и `n` колони е `O(mn)`.
- Квадратна матрица со `n` редици и `n` колони содржи `n²` елементи.
- Повеќедимензионалните низи го применуваат истиот принцип со три или повеќе индекси.

### Основни операции врз матрици

Основните операции врз матриците се:

1. Пристап до елемент – добивање вредност според редица и колона.
2. Изминување на матрицата – последователно посетување на сите елементи.
3. Пресметување збир – собирање на вредностите на сите елементи.
4. Собирање матрици – собирање на две матрици елемент по елемент.
5. Транспонирање матрица – заменување на редиците со колоните.

#### Пристап до елемент според индекси

Цел: Читање на вредноста на елементот на определена редица `i` и колона `j`.

| Карактеристика      | Опис                             |
|---------------------|----------------------------------|
| Предуслов           | `0 ≤ i < m` и `0 ≤ j < n`        |
| Резултат            | Вредноста на елементот `a[i][j]` |
| Временска сложеност | `O(1)`                           |
| Просторна сложеност | `O(1)`                           |

Алгоритам:

1. Започни.
2. Прими матрица `a` и индекси `i` и `j`.
3. Провери дали индексите се валидни.
4. Ако индексите не се валидни, пријави грешка.
5. Пристапи до елементот `a[i][j]`.
6. Прочитај ја вредноста на елементот.
7. Врати ја вредноста.
8. Заврши.

Java имплементација:

```java
int value = a[i][j];
```

Објаснување: Елементот се добива директно со користење на два индекси – првиот ја означува редицата, а вториот колоната.
Не е потребно пребарување низ останатите елементи.

#### Изминување на матрицата

Цел: Да се посетат сите елементи на матрицата по еднаш.

| Карактеристика      | Опис                        |
|---------------------|-----------------------------|
| Предуслов           | Матрицата е иницијализирана |
| Резултат            | Сите елементи се посетени   |
| Временска сложеност | `O(mn)`                     |
| Просторна сложеност | `O(1)`                      |

Алгоритам:

1. Започни.
2. Постави го индексот на редицата `i` на `0`.
3. Додека `i` е помал од бројот на редици `m`:
    - Постави го индексот на колоната `j` на `0`.
    - Додека `j` е помал од бројот на колони `n`:
        - Прочитај го тековниот елемент `a[i][j]`.
        - Изврши ја потребната операција врз елементот.
        - Зголеми го `j` за еден.
    - Премини на следната редица со зголемување на `i`.
4. Заврши.

Пример:

```text
Матрица:

[
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
]

Редослед на посетување:

10 → 20 → 30 → 40 → 50 → 60 → 70 → 80 → 90
```

Java имплементација:

```java
void print(int[][] a) {
    for (int i = 0; i < a.length; i++) {
        for (int j = 0; j < a[i].length; j++) {
            System.out.print(a[i][j] + " ");
        }

        System.out.println();
    }
}
```

Објаснување: Се користат две `for` петелки. Надворешната поминува низ редиците, а внатрешната низ колоните. Секој
елемент се посетува точно еднаш, па вкупниот број операции е `m × n`.

#### Пресметување збир на елементите

Цел: Да се пресмета збирот на вредностите на сите елементи во матрицата.

| Карактеристика      | Опис                        |
|---------------------|-----------------------------|
| Предуслов           | Матрицата е иницијализирана |
| Резултат            | Збир на сите елементи       |
| Временска сложеност | `O(mn)`                     |
| Просторна сложеност | `O(1)`                      |

Алгоритам:

1. Започни.
2. Иницијализирај променлива `sum` со вредност `0`.
3. Помини низ сите редици и колони.
4. За секој елемент додади ја неговата вредност во `sum`.
5. По завршувањето на изминувањето, врати го збирот.
6. Заврши.

Пример:

```text
Матрица:

[
    [1, 2, 3],
    [4, 5, 6]
]

Збир:

1 + 2 + 3 + 4 + 5 + 6 = 21
```

Java имплементација:

```java
int sum(int[][] a) {
    int sum = 0;

    for (int i = 0; i < a.length; i++) {
        for (int j = 0; j < a[i].length; j++) {
            sum += a[i][j];
        }
    }

    return sum;
}
```

Објаснување: Со две вгнездени петелки се посетуваат сите елементи. Вредноста на секој елемент се додава во променливата
`sum`, која на крај го содржи вкупниот збир.

#### Собирање матрици

Цел: Да се соберат две матрици елемент по елемент и да се добие резултантна матрица.

| Карактеристика      | Опис                                  |
|---------------------|---------------------------------------|
| Предуслов           | Матриците имаат исти димензии `m × n` |
| Резултат            | Нова матрица `C`                      |
| Временска сложеност | `O(mn)`                               |
| Просторна сложеност | `O(mn)`                               |

Алгоритам:

1. Започни.
2. Провери дали матриците имаат исти димензии.
3. Креирај нова матрица `C` со исти димензии.
4. Помини низ сите редици и колони.
5. За секоја позиција `(i, j)` пресметај:
   text
   ```text
   C[i][j] = A[i][j] + B[i][j]
   ```
6. Врати ја резултантната матрица `C`.
7. Заврши.

Пример:

```text
Матрица A:          Матрица B:

[1, 2, 3]           [7, 8, 9]
[4, 5, 6]           [1, 2, 3]


Резултат C:

[8, 10, 12]
[5,  7,  9]
```

Java имплементација:

```java
int[][] add(int[][] a, int[][] b) {
    if (a.length != b.length ||
            a[0].length != b[0].length) {
        System.out.println("Different dimensions!");
        return null;
    }

    int[][] c = new int[a.length][a[0].length];

    for (int i = 0; i < a.length; i++) {
        for (int j = 0; j < a[i].length; j++) {
            c[i][j] = a[i][j] + b[i][j];
        }
    }

    return c;
}
```

Објаснување: Двете матрици мора да имаат исти димензии. Со две вгнездени петелки се собираат соодветните елементи и
резултатот се запишува во нова матрица `C`.

#### Транспонирање квадратна матрица

Цел: Да се заменат редиците со колоните на квадратната матрица.

| Карактеристика      | Опис                  |
|---------------------|-----------------------|
| Предуслов           | Матрицата е квадратна |
| Резултат            | Транспонирана матрица |
| Временска сложеност | `O(n²)`               |
| Просторна сложеност | `O(1)`                |

Алгоритам:

1. Започни.
2. Помини низ елементите над главната дијагонала.
3. За секој елемент `a[i][j]`, каде што `j > i`:
    - Замени ја вредноста на `a[i][j]` со вредноста на `a[j][i]`.
4. Продолжи додека не се обработат сите парови елементи.
5. Заврши.

Пример:

```text
Пред:

[
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

Потоа:

[
    [1, 4, 7],
    [2, 5, 8],
    [3, 6, 9]
]
```

Java имплементација:

```java
void transpose(int[][] a) {
    for (int i = 0; i < a.length; i++) {
        for (int j = i + 1; j < a.length; j++) {
            int temp = a[i][j];
            a[i][j] = a[j][i];
            a[j][i] = temp;
        }
    }
}
```

Објаснување: Транспонирањето се врши со замена на елементите симетрични во однос на главната дијагонала. Елементите на
главната дијагонала остануваат непроменети. Бидејќи замената се врши во истата матрица, не е потребна дополнителна
матрица.

## Ретки матрици

### Дефиниција

**Ретка матрица (sparse matrix)** е матрица во која најголемиот дел од елементите имаат вредност нула.

Ако се чуваат сите позиции, вклучувајќи ги и нулите, може да се потроши многу меморија. Затоа може да се користи
репрезентација што ги чува само ненултите елементи.

Нека:

- `m` е бројот на редици;
- `n` е бројот на колони;
- `k` е бројот на ненулти елементи.

Кога `k` е значително помало од `mn`, репрезентацијата со ненулти елементи може да заштеди меморија.

### Репрезентација со тројки

Во репрезентацијата со тројки, секој ненулт елемент се запишува со три вредности:

1. Индекс на редицата.
2. Индекс на колоната.
3. Вредност на елементот.

Дополнително се чуваат димензиите на матрицата и бројот на ненулти елементи.

**Пример:**

```text
Матрица:

[
    [0, 0, 5],
    [0, 8, 0],
    [3, 0, 0]
]
```

Репрезентација со тројки:

```text
Ред  Колона  Вредност
 0      2       5
 1      1       8
 2      0       3
```

Матрицата има `3 × 3 = 9` позиции, но само три ненулти елементи.

Обичната матрица бара `O(mn)` простор, додека репрезентацијата со тројки бара `O(k)` простор за записите на ненултите
елементи. Димензиите и другите метаподатоци додаваат константен простор.

### Основни операции врз ретки матрици

Основните операции врз ретките матрици се:

1. Изминување на ненултите елементи – последователно посетување на сите елементи различни од нула.
2. Пристап до елемент според координати – добивање вредност според редица и колона.

#### Изминување на ненултите елементи

Цел: Да се посетат и обработат сите елементи на ретката матрица што се различни од нула.

| Карактеристика      | Опис                                       |
|---------------------|--------------------------------------------|
| Предуслов           | Ретката матрица е правилно иницијализирана |
| Резултат            | Сите ненулти елементи се посетени          |
| Временска сложеност | `O(k)`                                     |
| Просторна сложеност | `O(1)`                                     |

Алгоритам:

1. Започни.
2. Постави го индексот на првата тројка на `0`.
3. Додека индексот е помал од бројот на ненулти елементи `k`:
    - Прочитај ги редицата, колоната и вредноста на тековната тројка.
    - Изврши ја потребната операција врз елементот.
    - Премини на следната тројка.
4. Повторувај додека не се посетат сите `k` тројки.
5. Заврши.

Пример:

```text
Ретка матрица:

[
    [0, 0, 5],
    [0, 8, 0],
    [3, 0, 0]
]

Тројки (ред, колона, вредност):

(0, 2, 5)
(1, 1, 8)
(2, 0, 3)

Редослед на посетување:

5 → 8 → 3
```

Java имплементација:

```java
void traverse(int[][] sparse, int k) {
    for (int i = 0; i < k; i++) {
        int row = sparse[i][0];
        int col = sparse[i][1];
        int value = sparse[i][2];

        System.out.println("(" + row + ", " + col + ", " + value + ")");
    }
}
```

Објаснување: Секој ненулти елемент е претставен со тројка што содржи редица, колона и вредност. Се изминуваат сите
тројки, без обработување на нултите елементи. Бидејќи има вкупно `k` ненулти елементи, временската сложеност е `O(k)`.

#### Пристап до елемент според координати

Цел: Да се пронајде вредноста на елементот на определени координати `(i, j)` во ретката матрица.

| Карактеристика      | Опис                                                |
|---------------------|-----------------------------------------------------|
| Предуслов           | Координатите се валидни                             |
| Резултат            | Вредноста на бараниот елемент или `0` ако не постои |
| Временска сложеност | `O(k)`                                              |
| Просторна сложеност | `O(1)`                                              |

Алгоритам:

1. Започни.
2. Прими ретка матрица и координати `(i, j)`.
3. Провери дали координатите се валидни.
4. Започни пребарување од првата тројка.
5. За секоја тројка:
    - Спореди ја нејзината редица со `i`.
    - Спореди ја нејзината колона со `j`.
6. Ако координатите се совпаѓаат, врати ја вредноста.
7. Ако не се пронајде соодветна тројка, врати `0`.
8. Заврши.

Пример:

```text
Ретка матрица:

[
    [0, 0, 5],
    [0, 8, 0],
    [3, 0, 0]
]

Тројки:

(0, 2, 5)
(1, 1, 8)
(2, 0, 3)

Бараме елемент на координати (1, 1).

Резултат: 8

Бараме елемент на координати (0, 1).

Резултат: 0
```

Java имплементација:

```java
int get(int[][] sparse, int k, int row, int col) {
    for (int i = 0; i < k; i++) {
        if (sparse[i][0] == row &&
                sparse[i][1] == col) {

            return sparse[i][2];
        }
    }

    return 0;
}
```

Објаснување: Со линеарно пребарување се проверува секоја тројка. Ако се пронајдат бараните координати, се враќа
вредноста на елементот. Ако не постои соодветна тројка, тоа значи дека елементот е нула, па се враќа `0`.
