# JavaScript Overview

## History and Purpose of JavaScript

Created in 1995 by Brendan Eich at Netscape (originally named LiveScript), JavaScript was designed to add dynamic
capability and interactive behaviors to web pages within web browsers. It was submitted to Ecma International in 1996 to
establish a standardized, cross-platform scripting language specification (ECMA-262).

## JavaScript as a Programming Language

JavaScript is a high-level, dynamic, prototype-based, single-threaded, garbage-collected, multi-paradigm programming
language. It natively supports imperative, object-oriented (prototype-chain), and functional programming paradigms,
treating functions as first-class objects.

## JavaScript Use Cases

* **Client-Side Development:** Executing script in the user agent to manipulate the Document Object Model (DOM), handle
  user input events, perform client-side routing, and make asynchronous network requests (Fetch/XMLHttpRequest).
* **Server-Side Development:** Running back-end application logic, managing HTTP/WebSocket servers, connecting to
  database services, and handling file system streaming via server runtime environments (e.g., Node.js, Bun, Deno).
* **Desktop and Mobile Applications:** Compiling or packaging cross-platform desktop GUIs (e.g., via Electron or Tauri)
  and native mobile apps (e.g., via React Native, NativeScript, or Ionic).
* **Tooling and Automation:** Executing build systems, task runners, code formatters, linters, bundlers, and serverless
  CLI automation scripts (e.g., Webpack, Vite, ESLint).
