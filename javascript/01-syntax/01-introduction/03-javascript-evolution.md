# JavaScript Evolution

| Edition       | Year | Core Introduced Features                                                                                                                                                                                                                                            |
|---------------|-----:|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ES5           | 2009 | • `"use strict"` mode<br>• JSON support<br>• Array iteration methods (`map`, `filter`, `reduce`)<br>• `Object.defineProperty`<br>• Getters/Setters                                                                                                                  |
| ES6 / ES2015  | 2015 | • Block-scoped declarations (`let`, `const`)<br>• Arrow functions<br>• Promises<br>• ES Modules (`import`/`export`)<br>• Classes<br>• Template literals<br>• Destructuring<br>• Spread/Rest operators<br>• Iterators/Generators<br>• `Symbol`<br>• `Map`<br>• `Set` |
| ES2016 (ES7)  | 2016 | • `Array.prototype.includes()`<br>• Exponentiation operator (`**`)                                                                                                                                                                                                  |
| ES2017 (ES8)  | 2017 | • `async` / `await` syntax<br>• `Object.values()`<br>• `Object.entries()`<br>• String padding (`padStart()` / `padEnd()`)<br>• Shared memory and `Atomics`                                                                                                          |
| ES2018 (ES9)  | 2018 | • Asynchronous iteration (`for await...of`)<br>• Rest/Spread properties for objects<br>• `Promise.prototype.finally()`<br>• RegExp improvements (named groups, lookbehind assertions)                                                                               |
| ES2019 (ES10) | 2019 | • `Array.prototype.flat()` / `flatMap()`<br>• `Object.fromEntries()`<br>• `String.prototype.trimStart()` / `trimEnd()`<br>• Optional catch binding                                                                                                                  |
| ES2020        | 2020 | • `BigInt` primitive<br>• Nullish Coalescing operator (`??`)<br>• Optional Chaining (`?.`)<br>• `Promise.allSettled()`<br>• `globalThis`<br>• Dynamic `import()`                                                                                                    |
| ES2021        | 2021 | • `String.prototype.replaceAll()`<br>• `Promise.any()`<br>• Logical Assignment operators (`&&=`, `\|\|=`, `??=`)<br>• `WeakRef`<br>• `FinalizationRegistry`                                                                                                         |
| ES2022        | 2022 | • Class fields (private `#field`, static initialization blocks)<br>• Top-level `await`<br>• `Array.prototype.at()`<br>• `Object.hasOwn()`<br>• RegExp `/d` flag (indices)                                                                                           |
